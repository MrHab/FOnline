# Бриф главного архитектора v2 — СОГЛАСОВАН КОМИТЕТОМ

(v1 + 15 правок комитета: композиция, читаемость зума, техника.)

Мир: Realm of Ashes, техпустоши. Карта 900×900 км = диорама 90×90 юнитов,
координаты в «точках» 0–900 (1 точка = 1 км = 0.1 юнита). Океан — запад.
Эталон: кампания TW:W3 — читаемые биомы с зума, мелкие объекты, рваные
кромки, пустоты как часть композиции.

## Главный принцип читаемости (правка комитета)

Цвет биома с дальнего зума даёт ПОДКРАСКА ЗЕМЛИ (groundTint региона),
а не пропсы: объекты покрывают <2% площади. Пропсы — текстура среднего
зума и силуэты. Никаких «ковров» из инстансов.

не равномерной рассыпкой; сухое озеро 21 — читаемое пятно.

## Запретные зоны (в генераторе и в plan.json)

- радиус 55 от узлов (в коде генератора);
- солончак x 660–860, y 700–860 — глобальный exclusion, туда никто;
- дорожные коридоры: в 10 точках от осевой только декор ниже 0.25 ю (код);
- вода, кромка карты 40 точек (код).

## Правила палитр (обязательны для планировщиков)

- ≤ 12 уникальных префабов на регион; префабы с renderers > 8 отсекает
  генератор; бюджет запечённых материалов всей карты — 40.
- Деревья/кусты: ≥ 60% веса через групповые `_Grp_` префабы (одна группа
  = десятки растений за один объект). Кактусы — только `Cactus_C_Grp`.
- Папоротники/грибы/корни/мох-инстансы — НЕ использовать (субпиксель);
  тон даёт groundTint.
- Cracked_Mud — только в 21-drylake, крупные тайлы.
- Высоты: декор ≤ 0.5 ю (maxHeightWorld), скалы хребтов ≤ 0.9,
  явные ориентиры (landmarks) ≤ 1.0 и не больше 20 на всю карту.
- Масштаб: базовый 0.012 ю/м (plan.json), jitter scale.min–max 0.75–1.35;
  для крупности скал использовать boost правила, не общий масштаб.

## Схема файла региона

```json
{
  "id": "forest",
  "container": "Plan_Forest_AUTHORED",
  "bounds": { "xMin": 540, "xMax": 700, "yMin": 360, "yMax": 835 },
  "edgeFadePoints": 40,
  "noise": { "threshold": 0.5, "period": 60, "density": 0.55,
             "seed": 50, "stepPoints": 8 },
  "scale": { "min": 0.75, "max": 1.35 },
  "maxHeightWorld": 0.5,
  "quota": 1100,
  "groundTint": "#5E6B44",
  "groundTintStrength": 0.8,
  "excludeRects": [ { "xMin": 0, "xMax": 0, "yMin": 0, "yMax": 0 } ],
  "palette": [
    { "include": ["ConiferTrees/MEP_Con_01/MEP_Con_01_Grp"],
      "exclude": ["Snow"], "weight": 5, "boost": 1.0, "maxHeight": 0.5 }
  ],
  "landmarks": [
    { "path": "Assets/MEP/.../X.prefab", "x": 600, "y": 500,
      "yaw": 45, "scale": 1.0, "maxHeight": 1.0 }
  ]
}
```

include/exclude — подстроки, ищутся в «категория/имя» записи каталога
data/mep-catalog.json (категория = путь в паке). weight — относительный
вес выбора. Пустой exclude можно опустить. excludeRects можно опустить.
