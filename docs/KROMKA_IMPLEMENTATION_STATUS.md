## География

- Unity является источником пространственных данных. Экспорт из сцены
  глобальной карты обновляет `data/global-map.json`,
  `data/kromka/world-layout.seed.json`, `data/kromka/locations.json` и
  определения в `data/locations/`.
- Стабильные ID прежних локаций сохранены только для ссылок и миграции
  сохранений (`data/kromka/migration-aliases.json`); координаты, названия и
  композицию они не определяют.
- Личные базы, случайные встречи, сцены опасных клеток и осадные инстансы на
  публичной карте не видны; восемь клановых владений публичны.
- В Build Settings включены стартовая `Wasteland.unity`, `KromkaGlobalMap.unity` и сцены
  локаций из `Assets/Scenes/Kromka/Locations/`. `GlobalMapAuthored.unity` —
  архивный источник, в сборку не входит.

## Проверки

- `npm run check` — вся цепочка для CI и перед слиянием.
- `npm run check:kromka-lore` — канон и все KRM-контуры: данные, фракции,
  аномалии, обучение, мутанты, артефакты, предметы, личная база, жители,
  задания, кланы, осады, жизнь мира, прогрессия, бой, путешествия, ИИ, ПУТНИК,
  выпуск и зоны мира.
- `npm run check:kromka-world-life` — состояния поселений, беженцы, цикл
  Сдвигов и детерминированный семисуточный прогон.
- `npm run check:kromka-character-terms` — каталог 7/16/41, бюджет 40, миграция
  журнала вложений, идемпотентный повтор и сохранение очков после рестарта.
- `npm run check:world-model`, `check:danger-cells`, `check:danger-ecology`,
  `check:account-sin`, `check:black-market`, `check:crafting-plots` — экономика v3.
- `npm run check:unity-csharp` компилирует Unity C# вне редактора. Требует
  установленного Unity и импортированного проекта, поэтому в `npm run check` и
  CI (Linux без Unity) не входит.
- `data/wasteland-sim.json` и остальные файлы `DATA_DIR` — непубликуемое
  runtime-состояние; в авторские `data/` их не переносят.
