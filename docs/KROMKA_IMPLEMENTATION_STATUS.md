KRM-14 подключён к действующей автономной симуляции полностью. Мигранты больше
не исчезают из чисел: сервер создаёт одну агрегированную группу, ведёт её к
ближайшему доступному поселению с водой и охраной, переносит население один раз
по прибытии и открывает причинный гуманитарный контракт. Нехватка, угроза и
восстановление материализуют ограниченные очереди, баррикады и ремонтные
бригады. Семидневный детерминированный прогон пройден.

KRM-15 завершён. `data/kromka/character-progression.json` является единым
источником пользовательских названий, требований и лимитов для сервера,
редактора персонажа и ПУТНИКА. Сервер отклоняет бюджет не ровно в 40 очков,
возвращает причину отказа прокачки и хранит версионный журнал вложенных шагов
навыков. Проверка с реальным HTTP/Socket.IO проходит создание по старому alias,
миграцию сохранения без журнала, повтор одного запроса и рестарт без изменения
свободных очков.

KRM-16 завершён. PvE и PvP используют общий порядок «крит → порог → броня →
сопротивление → травма» для восьми типов урона. Природные сопротивления
мутантов больше не определяются по имени. Состояние «ранен» сохраняется при
переподключении, поднятие возвращает 30% ОЗ, обычная смерть — 55% ОЗ в
последнем безопасном поселении, а осада сохраняет собственные волны. Выпадение
предметов ограничено одной транзакцией смерти. Unity показывает режим зоны,
стоимость ОД, режим огня, требование Мощи и, при наличии «Осведомлённости»,
порог, броню и сопротивление цели. Первый вход в полный лут требует отдельного
подтверждения.

KRM-17—KRM-20 завершили сверку дизайн-документа с текущей игрой. Они закрепили
единые каталоги предметов и рецептов, восстановление маршрутов, авторитетные
встречи, LOS всех контекстных действий, версионированные данные ПУТНИКА и
идемпотентные социальные операции. Патчи стабилизируют существующие системы,
а не заменяют их новой реализацией с нуля.

KRM-18 восстанавливает полный маршрут и назначение после reconnect. Контакт со
встречей определяется сервером, останавливает прогресс пути и имеет 15 секунд
на решение лидера; подменить идентификатор или заголовок клиентом нельзя.

KRM-19 использует одну серверную LOS для зрения ИИ и взаимодействий. Диалоги,
лечение, торговля, крафт, добыча, задания, лут, замки и терминалы нельзя
активировать через препятствие. Глобальная камера имеет `CameraAnchor Y = 0`
и диапазон 1–20; дальность снижает только стоимость анимации.

KRM-20 публикует контракты, мир, задания, репутацию, друзей, клан и убежище в
`kromka.ui-snapshots.v1`. ПУТНИК применяет эти снимки как источник страниц.
Критические запросы получают `requestId`; журнал повтора переживает сохранение
и reconnect. Права личной базы, временной группы и клана публикуются отдельными
областями полномочий. Детектор и арт-пояс остаются слотами инвентаря, а не
постоянными панелями HUD.

## Лорная география — источник карты

- Активная карта больше не повторяет форму и биомы прежнего региона. Её причинная схема строится вокруг Тесьмы, Каскада, Большого Тракта, Рудной ветви, Стеколья и Нулевой котловины.
- Unity является источником пространственных данных. Глобальная сцена содержит 39 физических узлов и 5 маршрутов; экспорт обновляет `data/global-map.json`, `data/kromka/world-layout.seed.json`, `data/kromka/locations.json` и определения в `data/locations/`.
- Стабильные старые ID сохранены только там, где нужны для ссылок и миграции сохранений. Они не определяют координаты, названия, климат или композицию нового мира.
- Все 39 постоянных узлов, видимых на глобальной карте, доступны для входа. Журнал и порядок глав по-прежнему открывают их сюжетное назначение последовательно. Личные базы, случайные встречи и осадные инстансы не видны на публичной карте; восемь клановых владений остаются публичными.
- Архивные сцены `GlobalMapAuthored.unity` и старых Ключей исключены из Build Settings и не используются активным клиентом.

## Игровые контуры

Новый персонаж начинает в приватном Сборном дворе №12: подписывает контракт, получает снаряжение и проходит движение, укрытия, лечение, болт, ремонт и выход. После подготовки игрок переживает засаду на караван «Двенадцатый» и прибывает в Ключи. Свободная MMO-песочница открывается после первой миссии, а её решения записываются в сюжетное состояние.

Все аномалии постоянно различимы визуально или по звуку и почти все разряжаются обычным многоразовым болтом. Сервер проверяет дальность 10 м, задержку 0,75 с, препятствия и пересечение с полем. Детектор занимает отдельный слот. Артефакты проходят горячую и стабилизированную стадии и дают числовые бонусы к скорости, ОД, грузоподъёмности, силе, здоровью, лечению, регенерации и сопротивлениям.

Личная база является приватной серверной комнатой владельца. Постройки и производственные задания имеют стоимость и время и продолжаются офлайн. Приглашённые NPC остаются на базе: открывают рецепты, лечат, охраняют и улучшают производство, но никогда не следуют за игроком как боевой отряд.

У клана может быть одно публичное владение. Осада объявляется минимум за 24 часа, проверяет 72 часа членства и блокирует состав за час до начала. Матч проходит в отдельной комнате тремя фазами — ретрансляторы, пролом и ядро. Содержимое склада не выпадает; меняются владелец, повреждения модулей и награды.

Каждое из восьми владений теперь имеет серверный недельный доход и собственный
эффект: экономию топлива/реагентов/воды, дополнительный выход деталей,
реагентов или медицины, увеличенный склад, ускорение однокланового каравана,
ранний прогноз Сдвига либо защищённый сбор. Особые заказы имеют серверную цену
и кулдаун; бонус прекращается вместе с потерей владения.

## Unity и визуальный аудит

- Использован Unity 6000.5.8f1, URP.
- Глобальная сцена снова содержит полный набор из 20 модельных проходов:
  2030 активных рендереров и 124 материала формируют города, Factory Kit,
  лорные комплексы, пять переправ, шесть придорожных узлов и ЛЭП из восьми
  опор. Проверено: 0 объектов за кромкой, 0 чрезмерно крупных моделей,
  0 активных коллайдеров и 0 дистанционных LOD-групп.
- Модели Car Kit 3.1, Factory Kit 3.0 и City Kit Industrial 2.0 используют
  родные атласы `colormap.png`; авторская однотонная перекраска этих наборов
  отключена.
- В Build Settings включено 47 сцен: стартовая `Wasteland`, глобальная карта «Кромки» и 45 локаций.
- Все локации имеют отдельные редактируемые сцены, безопасные точки появления, физические границы, тематические корни `REGION_LANGUAGE_*`, `LOCATION_TYPE_*` и редактируемое наполнение `ATMOSPHERIC_DRESSING_EDITABLE`.
- Проверка `Кромка/Проверки/Авторские сцены` пройдена после сохранения и повторного открытия сцен; проверены 39 узлов, 5 маршрутов, ссылки сборки, аномалии, 12 ячеек личной базы и структура клановых арен.
- Набор из 11 контрольных кадров 1600×900 сохранён в `Build/KromkaSceneCaptures/`: глобальная карта, обучение, столицы, личная и клановая базы, мутантская зона и лаборатория.
- WebGL-сборка завершена успешно: 102 МБ за 35:23, выходной каталог `public/unity/`; загрузочная страница ссылается на четыре существующих ненулевых хешированных файла общим объёмом 107 914 605 байт.

## Проверки

- `npm run check:kromka-lore` проверяет KRM-00—KRM-20, включая runtime-предметы,
  маршруты, LOS/ИИ, серверные снимки ПУТНИКА и безопасный P2P-обмен.
- `npm run check:kromka-world-life` проверяет состояния поселений, миграцию,
  агрегированные группы беженцев, идемпотентное прибытие, гуманитарную помощь,
  локальные варианты, границы цен, физический груз, причинный цикл Сдвигов и
  детерминированный семисуточный прогон.
- `npm run check:kromka-item-instances` проверяет перенос заряженного оружия с
  состоянием и модулями через землю, хранилища и атомарный обмен игроков.
- `npm run check:kromka-character-terms` проверяет единый каталог 7/16/41,
  бюджет 40, канонические названия, загрузку каталога Unity, причины отказа,
  alias быстрого старта, миграцию журнала вложений, идемпотентный повтор и
  сохранение тех же очков после рестарта.
- `npm run check:kromka-travel` проверяет восстановление маршрута, серверный
  контакт встречи, таймер решения лидера и целостность временной группы.
- `npm run check:kromka-perception` проверяет серверную LOS взаимодействий,
  зрение/слух ИИ, fog-of-war, камеру и отсутствие distance-culling акторов.
- `npm run check:kromka-ui` проверяет версионированные снимки, раздельные права,
  replay-safe действия, ПУТНИК, контекстные артефакты и пользовательские строки.
- `npm run check:kromka-lore`, `npm run check:kromka-terminology`, полная
  предварительная матрица и основная матрица `check` пройдены на этом срезе.
  Последний серверный smoke подтверждает `/health`, мировые API и общую
  неограниченную комнату для трёх игроков. `check-world-data` подтверждает 46
  локаций и 987 статических препятствий с явными правилами видимости.
- `npm run check:unity-csharp` компилирует актуальный runtime-набор Unity C# вне
  редактора по его же библиотечным ссылкам; остаются только прежние
  предупреждения сторонней камеры.
- Этот нативный компилятор требует установленного Unity и импортированного
  проекта (`Library/Bee`). Он запускается отдельно от переносимой Node-матрицы
  `npm run check`, поскольку GitHub Actions использует Linux без Unity.
  Полная локальная UI-проверка: `npm run check:kromka-ui-native`; отсутствие
  Unity в `check:unity-csharp` по-прежнему является ошибкой, а не успешным пропуском.
- HTTP/Socket.IO smoke подтверждает запуск «Кромки», публичные назначения, столицы-хранилища, независимого наёмника и общую MMO-комнату.
- Локальный `data/wasteland-sim.json` остаётся непубликуемым runtime-состоянием.
  Его записи не следует вручную переносить в авторские `data/`; после решения
  правила дорожных соединений снимок должен обновляться штатной миграцией.
