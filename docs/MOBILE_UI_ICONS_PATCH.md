# v7.74.26 — мобильные иконки UI

Изменения:

- Добавлены прозрачные PNG-иконки для мобильного UI в `public/assets/ui/mobile/`.
- Левое мобильное меню больше не использует emoji/символы как видимые иконки.
- Заменены все 7 кнопок левого меню, включая нижние кнопки `Туман войны` и `Присесть`.
- Для защиты от белого фона иконки подключены через CSS `::before`, исходный текст кнопок скрыт, `aria-label` сохранены.
- Подключены прозрачные иконки для fullscreen, главного меню и основных правых touch-кнопок.

Проверка:

- `node --check server.js`
- `node --check tools/check-client-js.js`
- `node tools/check-client-js.js`
- `node tools/check-client-css.js`
