# Аномалии: VFX и проверка механик — 12 сентября 2026

Обновлён активный Unity-клиент; legacy-клиент не изменялся. Существующие ID,
координаты и радиусы десяти авторских полей сохранены. Урон и разрядка остаются
серверными. Новые изображения ниже — кадры Unity Play Mode, не концепт-арт.

## Визуальная переработка

Вместо однослойных светящихся окружностей используются процедурный след на земле,
движущаяся атмосфера, частицы, фрагменты и, для электрических полей, многослойные
разряды. Есть постоянное состояние, отклик на контакт, затухание и восстановление.
Детектор не требуется для видимости опасности.

| Тип | Визуальный характер |
| --- | --- |
| Тяга | Пыль сходится к центру и поднимается; вокруг вращаются обломки |
| Шов | Узкий раскалённый разрыв, дрожащие нити и выброс вдоль разреза |
| Карусель | Спиральный поток пыли с высотой, орбитальные частицы и обломки |
| Стекло | Нестабильная сетка горячих прожилок и восходящие искры |
| Роса | Низкая зелёная дымка, взвесь и всплеск капель |
| Провал | Пыль стягивается вниз, по краям проявляются неровные трещины |
| Звон | Меняющиеся электрические ветви с короной и светлой сердцевиной |
| Молчун | Тёмная дымка с холодными светлыми прядями, втягивающий отклик |

Художественный ориентир — атмосферность STALCRAFT, а не копирование ресурсов.
Для актуального направления использован [официальный патчноут EXBO от 08.07.2026](https://forum.exbo.net/d/190810-patchnout-08072026),
включая изменения тумана и грозы. Это оригинальная реализация для изометрической
камеры Realm of Ashes. Равенство качества с коммерческой игрой не измерялось;
экранная рефракция и объёмный raymarching здесь не реализованы.

## Исправленные ошибки

1. **Зеркальное положение VFX по Z.** Визуальный центр раньше расходился с серверной
   зоной урона. Теперь применяется тот же `RoaCoords.ToUnity`, что для мира и игроков.
2. **Неправильный канал урона Росы.** `chemical` не являлся каналом боевого контракта;
   теперь используется `toxic`, включая совместимость со старым обозначением.
3. **Исчезающие русские названия состояний.** Название больше не проходит очистку
   как технический ASCII-идентификатор.
4. **Избыточный урон при пересечении границы.** Выход и быстрый повторный вход не
   сбрасывают интервал урона; время вне поля не накапливает дополнительный удар.
5. **Неверный выбор поля болтом.** Выбирается первое пересечение границы по траектории,
   а не ближайший центр. Разряженные поля больше не перехватывают следующие болты.
6. **Препятствие за аномалией блокировало попадание.** Проверяется путь до фактического
   контакта; препятствие перед ним по-прежнему запрещает бросок.
7. **Несовпадение болта и реакции.** Сервер отправляет точку контакта, клиент завершает
   там полёт. Универсальный синий отклик заменён реакцией соответствующего поля.
8. **Повторные и устаревшие состояния.** Повторный пакет не запускает новый всплеск
   и не продлевает локальное затухание. Старые ревизии и пакеты прежней комнаты
   отбрасываются. Постоянная разрядка не восстанавливается по таймеру.
9. **Изменение авторского поля.** Смена типа или радиуса пересоздаёт соответствующий
   эффект; переход между комнатами удаляет старые частицы, материалы и звук.
10. **Дальность магнитного болта в интерфейсе.** Прицеливание раньше обрезало любой
    бросок до 10 м. Теперь сервер сообщает разрешённую дальность, включая 13 м после
    задания. Постоянная разрядка больше не описывается как «примерно на 1 с»;
    временная длительность рассчитывается по часам сервера.

## Производительность и границы проверки

- На поле: максимум **110 частиц** в обычном режиме или **43** в облегчённом.
- Буферы переиспользуются; качество меняется без создания частиц каждый кадр.
- Детальные частицы/разряды отключаются за 80 м, в облегчённом режиме — за 50 м.
- След на земле не зависит от bloom, depth/opaque-текстур или compute shaders.
- Мобильная проверка: 960×540, облегчённый бюджет и отключённая постобработка.
  Это эмуляция в редакторе, не замер FPS на физическом телефоне или в WebGL.
- На тестовом стенде 8 полей видны одновременно. Его бетонный фон намеренно
  не заменялся во время художественной итерации.

## Проверки

- `npm run check:anomaly-runtime`: чистые тесты и настоящий локальный сервер,
  `/health`, два Socket.IO-клиента, общая разрядка, точка контакта, защита от
  подделки начала броска/магнитного улучшения и соблюдение задержки.
- `RoaAnomalyVfxProbe.RunBatch`: координаты, восемь типов, бюджеты,
  повторные/устаревшие состояния, постоянная разрядка, радиус, очистка.
- `RoaAnomalyVfxProbe.RunVisualBatch`: активное поле, всплеск, затухание,
  восстановление в облегчённом режиме. В Play Mode проверяются повторный пакет,
  восстановление по таймеру без нового пакета и работа частиц дольше первого цикла.
- `RoaAnomalyVfxProbe.RunLocationBatch`: авторская solarArray, игровые координаты,
  обычная игровая камера, desktop/mobile, без соединения с production.
- `compile-check.ps1`: компиляция C# без ошибок; в проекте остаются существующие предупреждения.
- `npm run check:unity-parity`, проверки механик и артефактов.
- Полный `npm run check` запущен, но остановился на существующем ограничении
  `check:retired-environment-glbs`: `tutorialCaravanYard.json: yard_cover_a`.
  Коллизия постороннего объекта в рамках этой работы не удалялась.
