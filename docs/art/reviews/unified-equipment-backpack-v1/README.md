# Рюкзак B+C

Утверждённый походный рюкзак построен непосредственно на актуальном 65-костном скелете игрока. Для каждого сочетания пола и телосложения ширина рамы, положение лямок и высота груза пересчитываются по фактическим размерам корпуса.

## Конструкция

- жёсткая внешняя рама с двумя направляющими и тремя поперечинами;
- основной мешок из выцветшей оливковой ткани с клапаном и компрессионной панелью;
- два боковых кармана, верхний грузовой свёрток и нижний спальник;
- объёмные плечевые лямки, нагрудная перемычка, поясной ремень и отдельные пряжки;
- ручка, полевая заплата и окисленная металлическая фурнитура;
- материалы B+C: приглушённая ткань, состаренная коричневая стропа, потёртая рама, пыльный спальник и выцветшая ремонтная метка.

## Совместимость с бронёй

Лямки и грузовая часть экспортированы отдельными skinned-слоями. Лямки остаются на теле, а рама с грузом автоматически отодвигается назад в зависимости от толщины надетой брони. Проверка включает все утверждённые костюмы, включая тяжёлую броню.

## Проверка

```text
node tools/check-backpack-model.js
npm run build:approved-humanoids
npm run check:approved-humanoids
```

В каталоге `backpack/` находятся шесть исходных GLB, отчёты и задние рендеры. Для `male_medium` дополнительно сохранены фронтальный и детальный рендеры, а также сцена Blender для визуального аудита.
