# Бронежилет B+C — ревью-комплект

Статус: источник подготовлен для интеграции. Игровые копии выпускаются детерминированным сборщиком утверждённых моделей и не редактируются вручную.

## Художественное направление

- геометрия B: лёгкий и функциональный силуэт несущего чехла, отличимый от металлической и боевой брони;
- материалы и износ C: выцветшая оливковая ткань, тёмные баллистические вставки, пыльная стропа, окисленная фурнитура и полевая заплата;
- передняя и задняя вставки повторяют объём торса и соединены боковым поясом;
- широкие регулируемые плечевые ремни оставляют руки свободными;
- три подсумка, крупные MOLLE-стропы, центральная пряжка и задняя эвакуационная ручка читаются с игровой камеры;
- чистый нижний пояс закрывает ступенчатый край исходной low-poly поверхности тела.

## Варианты

В каталоге `vest/` находятся отдельные скелетные GLB для:

- `female_slim`, `female_medium`, `female_large`;
- `male_slim`, `male_medium`, `male_large`.

Каждый вариант использует текущий 65-костный риг персонажа. Фронтальные рендеры проверяют посадку на всех телах; для `male_medium` дополнительно сохранены вид сзади, крупный план и рабочая сцена Blender. Сводный отчёт находится в `vest/fit-report-all.json`.
