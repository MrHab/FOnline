# Боевая броня B+C — ревью-комплект

Статус: источник подготовлен для интеграции. Игровые копии выпускаются детерминированным сборщиком утверждённых моделей.

## Художественное направление

- геометрия B: цельный изготовленный комплект между лёгким бронежилетом и будущей тяжёлой бронёй;
- материалы и износ C: графитовая поддёвка, сколотый оливковый композит, тёмные амортизирующие вставки, потускневший сплав и выцветшая ремонтная пластина;
- нагрудник и спинка повторяют торс, а две нижние секции сохраняют подвижность живота;
- наплечники, предплечья и передне-внешняя сторона бёдер защищены отдельными деталями;
- набедренные пластины открыты с внутренней стороны и удерживаются двумя тканевыми стропами, не образуя жёстких колец вокруг ног;
- отдельная обувь остаётся совместимой: броня не закрывает голени и стопы.

В `armor/` находятся шесть вариантов для `female_slim`, `female_medium`, `female_large`, `male_slim`, `male_medium`, `male_large`. Все используют текущий 65-костный риг; сводный отчёт находится в `armor/fit-report-all.json`.
