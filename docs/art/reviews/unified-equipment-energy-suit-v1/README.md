# Энергозащитный костюм B+C — ревью-комплект

Статус: ревью-источник утверждён для интеграции; игровые runtime-копии выпускаются сборщиком утверждённых человекоподобных ассетов.

## Художественное направление

- геометрия B: лёгкий технический комбинезон, а не массивная силовая броня;
- материалы и износ C: выцветший графитовый композит, матовая изоляция, потемневшие медные проводники, сколотая синяя керамика и потёртое полевое стекло;
- компактный грудной регулятор распределяет поле по тонким каналам и не мешает двуручному хвату оружия;
- грудная защита разделена на две небольшие панели, поэтому корпус остаётся подвижным в ходьбе, беге и прицеливании;
- высокий изолирующий воротник не закрывает лицо и совместим со всеми причёсками;
- задний конденсатор состоит из одного защищённого элемента и двух охлаждающих рёбер, не превращаясь в громоздкий рюкзак;
- перчатки и защитные носки артикулированы вместе с пальцами и стопами, поверх них можно подключить отдельную обувь.

## Варианты

В каталоге `suit/` находятся отдельные скелетные GLB для:

- `female_slim`, `female_medium`, `female_large`;
- `male_slim`, `male_medium`, `male_large`.

Все варианты построены по реальной поверхности соответствующего базового тела и используют текущий 65-костный риг персонажа. Сводный отчёт находится в `suit/fit-report-all.json`.

`equipment_energy_suit_unified_v1_male_medium_review.blend` содержит сцену Blender с персонажем, освещением и тестовой позой. PNG предназначены для визуальной проверки; исходные GLB остаются неизменяемыми ревью-ассетами, а игра использует выпущенные из них runtime-копии.
