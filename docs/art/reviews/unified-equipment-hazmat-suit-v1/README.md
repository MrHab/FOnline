# Костюм химзащиты B+C — ревью-комплект

Статус: ревью-источник утверждён для интеграции; игровые runtime-копии выпускаются сборщиком утверждённых человекоподобных ассетов.

## Художественное направление

- геометрия B: цельный утилитарный силуэт без фантастической брони и чрезмерно крупных деталей;
- материалы и износ C: выцветшая горчичная прорезиненная ткань, состаренная чёрная резина, потёртый поликарбонат и окислившийся металл;
- герметичный капюшон с настоящим проёмом под панорамный визор, компактный двухфильтровый респиратор, закрытая молния и измеряемый поясной шов;
- артикулированные перчатки и защитные носки повторяют пальцы и стопы персонажа, сохраняя возможность надеть отдельные ботинки поверх;
- внутренний герметичный слой закрывает швы исходного тела при сильных изгибах, а наружная оболочка создаёт мягкий объём костюма;
- небольшие ремонтные заплаты и знак заражения дают читаемый износ, не превращая костюм в случайный набор лоскутов.

## Варианты

В каталоге `suit/` находятся отдельные скелетные GLB для:

- `female_slim`, `female_medium`, `female_large`;
- `male_slim`, `male_medium`, `male_large`.

Каждый вариант построен непосредственно по поверхности соответствующего базового тела и использует текущий 65-костный риг персонажа. Сводный отчёт находится в `suit/fit-report-all.json`.

`equipment_hazmat_suit_unified_v1_male_medium_review.blend` содержит сцену Blender с персонажем, освещением и тестовой позой. PNG рядом предназначены для визуальной проверки; исходные GLB остаются неизменяемыми ревью-ассетами, а игра использует выпущенные из них runtime-копии.
