# Тяжёлая броня B+C

Утверждённый комплект тяжёлой брони построен непосредственно на актуальном 65-костном скелете игрока. Для каждого сочетания пола и телосложения геометрия заново измеряет торс, плечи, предплечья, таз и бёдра; варианты не получают простое масштабирование одной модели.

## Конструкция

- двухслойный нагрудник и широкая задняя плита;
- высокий открытый ворот, не перекрывающий лицо и поворот головы;
- три подвижные брюшные пластины и трёхсекционная защита таза;
- задняя сервисная рама с двумя силовыми направляющими;
- массивные наплечники и наручи с освобождёнными подмышками и локтями;
- внешние бедренные щитки с открытой внутренней стороной ног;
- материалы B+C: тёмная подкладка, изношенный оружейный металл, оливковые композитные вставки, состаренная стропа, окисленная фурнитура и выцветшие ремонтные метки.

## Проверка

```text
node tools/check-heavy-armor-model.js
npm run build:approved-humanoids
npm run check:approved-humanoids
```

В каталоге `armor/` находятся шесть исходных GLB, отчёты и фронтальные рендеры. Для `male_medium` дополнительно сохранены задний и детальный рендеры, а также сцена Blender для визуального аудита.
