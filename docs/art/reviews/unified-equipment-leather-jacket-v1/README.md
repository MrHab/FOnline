# Кожаная куртка B+C — ревью-комплект

Статус: ревью-источник утверждён для интеграции; игровые runtime-копии выпускаются сборщиком утверждённых человекоподобных ассетов.

## Художественное направление

- геометрия B: цельный читаемый силуэт без фэнтезийной брони и лишних мелких деталей;
- материалы и износ C: приглушённая тёмно-коричневая кожа, матовая потёртая поверхность и состаренная металлическая фурнитура;
- отдельные лацканы, задняя стойка воротника, молния с бегунком, пояс с пряжкой, обтачка низа, заклёпки и локтевые усиления;
- оболочка снимается с реальной поверхности каждого базового тела, сваривается, сглаживается и получает физическую толщину;
- рукава заканчиваются до влияния костей кисти, поэтому при анимации не вытягиваются вслед за пальцами.

## Варианты

В каталоге `jacket/` находятся отдельные скелетные GLB для:

- `female_slim`, `female_medium`, `female_large`;
- `male_slim`, `male_medium`, `male_large`.

Каждый вариант использует текущий 65-костный риг персонажа и имеет собственный отчёт посадки с контрольной суммой. Сводные данные находятся в `jacket/fit-report-all.json`.

`equipment_leather_jacket_unified_v1_male_medium_review.blend` содержит сцену Blender с персонажем, освещением и тестовой A-позой. PNG рядом предназначены только для визуальной проверки.
