# Металлическая броня B+C — ревью-комплект

Статус: источник подготовлен для интеграции. Игровые копии выпускаются детерминированным сборщиком утверждённых моделей и не редактируются вручную.

## Художественное направление

- геометрия B: цельный, легко читаемый силуэт утилитарной брони пустоши;
- материалы и износ C: тусклая сталь, окисленные кромки, состаренные ремни и тёмная стёганая подкладка;
- нагрудная и задняя пластины повторяют объём тела, а не висят плоскими коробками;
- три перекрывающиеся брюшные пластины оставляют пояс подвижным;
- наплечники и наручи измеряются отдельно по рукам каждого базового тела;
- крупные заклёпки, центральное ребро и ремонтная накладка сохраняют читаемость с игровой камеры.

## Варианты

В каталоге `armor/` находятся отдельные скелетные GLB для:

- `female_slim`, `female_medium`, `female_large`;
- `male_slim`, `male_medium`, `male_large`.

Каждый вариант использует текущий 65-костный риг персонажа. Фронтальные рендеры проверяют посадку на всех телах; для `male_medium` дополнительно сохранены вид сзади, крупный план и рабочая сцена Blender. Сводный отчёт и контрольные суммы находятся в `armor/fit-report-all.json`.
