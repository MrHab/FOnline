# Разведботинки B+C

Новые разведботинки построены на утверждённой анатомической посадке обуви v21 и заново привязаны к актуальному 65-костному скелету для каждого пола и телосложения. Это отдельная лёгкая полевая модель, а не перекраска обычных или усиленных ботинок.

## Конструкция

- гибкий носовой бампер вместо тяжёлого стального подноска;
- пылезащитная гетра и два узких стабилизирующих ремня;
- фасонная наружная накладка лодыжки с выцветшей маршрутной меткой;
- задний упор, повторяющий форму пятки, и отдельная петля для надевания;
- пять неглубоких раздельных грунтозацепов на каждой подошве;
- материалы B+C: тёмная выветренная кожа, выгоревшая оливковая ткань, пыльная гетра, старая стропа, гибкая резина и тусклая фурнитура.

## Посадка и анимации

Для всех шести тел сохранены отдельные GLB, фронтальный ракурс и контрольные кадры `walk`/`run`. Носок, подошва и верх распределены между костями `foot`, `ball` и `calf`, поэтому стопа сгибается внутри обуви, а защитные детали не растягиваются вслед за пальцами.

## Проверка

```text
node tools/check-scout-boots-model.js
npm run build:approved-humanoids
npm run check:approved-humanoids
```

Для `male_medium` дополнительно сохранены боковой, задний, детальный и игровой изометрический ракурсы, а также исходная сцена Blender.
