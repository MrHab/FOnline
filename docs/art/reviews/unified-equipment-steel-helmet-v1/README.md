# Стальной шлем B+C — ревью-комплект

Статус: ревью-источник утверждён для интеграции; игровые runtime-копии выпускаются сборщиком утверждённых человекоподобных ассетов.

## Художественное направление

- геометрия B: цельный читаемый низкополигональный силуэт без фэнтезийного декора;
- материалы и износ C: тёмная потёртая сталь, вытертые кромки, приглушённая ржавчина и старый кожаный ремень;
- штампованный округлый купол с небольшой асимметричной вмятиной;
- усиленный прокатанный обод, продольное ребро, заклёпки и отдельная затылочная пластина;
- ремень проходит по сторонам челюсти и имеет металлическую пряжку слева;
- причёски не увеличивают объём шлема: игровой код уже скрывает волосы при любом экипированном шлеме.

## Посадка и варианты

В каталоге `helmet/` находятся отдельные скелетные GLB для:

- `female_slim`, `female_medium`, `female_large`;
- `male_slim`, `male_medium`, `male_large`.

Каждый вариант построен по фактическим границам головы соответствующего базового тела и полностью привязан к кости `head` текущего 65-костного рига. Поэтому четыре формы лица масштабируют голову и шлем совместно, сохраняя исходные зазоры без пересечений.

У каждого варианта есть собственный JSON-отчёт и фронтальный рендер. Для `male_medium` дополнительно подготовлены боковой, задний и детальный ракурсы, а также исходная сцена Blender.

## Техническая сводка

- 782 треугольника;
- один скелетный меш и один skin;
- 65 костей текущего рига;
- четыре материала: основная сталь, вытертые кромки, окисление и кожаный ремень;
- 12 упакованных карт PBR;
- автоматическая проверка всех восьми сочетаний пола и формы лица;
- `reviewOnly: true`, интеграция в runtime не выполнялась.

Сводный результат проверки находится в `helmet/fit-report-all.json`.
