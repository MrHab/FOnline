# Устранение конфликта сцен Wasteland / wasteland

Сцена локации переименована из
`Assets/Scenes/Kromka/Locations/wasteland.unity` в
`Assets/Scenes/Kromka/Locations/KromkaGloomDetour.unity`.
Стартовая сцена `Assets/Scenes/Wasteland.unity` не переименовывалась.

Игровой ID `wasteland`, название по лору, расстановка и игровые компоненты
сохранены. GUID сцены: `f26ecd2301bfc064ebd67ef106f168a6`.
SHA-256 содержимого сцены до и после переноса одинаков:
`6453210B8CF2A5E9CF82891DF868CA37DA0AD10941E35006C31FE890DA417B5F`.

`KromkaLocationSceneCatalog` явно сопоставляет игровой ID новому имени сцены.
Обновлены Build Settings, каталог локаций, определение `wasteland`, производный
мир и ссылка глобальной карты. Генератор, экспортёр, аудит и снимки сцен
используют общий `ScenePath`, поэтому следующая пересборка не вернёт конфликт.
Проверки данных используют явные пути сцен вместо предположения «имя = ID».

Добавлена проверка уникальности имён включённых сцен без учёта регистра.
Редакторская проверка `Кромка/Проверки/Загрузка переименованной локации`
дважды вызывает настоящий `RoaLocationLoader.LoadLocation`, затем выгружает
локацию. Проверяются путь, компонент `RoaUnityLocationScene`, игровой ID,
авторская поверхность и отсутствие дубликата стартовой сцены.
Проверка работает офлайн, без запуска сетевого bootstrap и изменения сохранений.

Результат: оба цикла успешны; загрузчик находит 39 объектов без ошибок.
Проверки каталога, ревизии мира, ссылок префабов, Unity parity и компиляция
323 C#-файлов прошли. Полный `npm run check` завершился с кодом 0,
включая завершающий сетевой smoke-тест. Локальные журналы находятся в
`Build/LocationSceneLoading/` и не предназначены для коммита.
