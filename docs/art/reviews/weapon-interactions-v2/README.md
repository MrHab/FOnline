# Хваты и перезарядки оружия v2

Набор переводит девять огнестрельных моделей на физические точки взаимодействия в направлении B+C.

## Покрытие

- `pistol` — съёмный магазин;
- `rifle` — патронная обойма и движение затвора;
- `assaultRifle` — отделённый из утверждённой геометрии изогнутый магазин;
- `machineGun` — короб боеприпасов;
- `laserPistol` и `plasmaRifle` — энергоячейки;
- `flamethrower` — топливный бак;
- `shotgun` — отдельный патрон и движение цевья;
- `rocketLauncher` — извлекаемая ракета.

Для ножа, кирки, топора и ручного насоса сохранены только осмысленные точки хвата: перезарядка этим предметам не назначается.

`build-report.json` фиксирует результат процедурной Blender-сборки всей библиотеки. Строка `assaultRifle` в нём описывает временную процедурную заготовку; в окончательном игровом манифесте она всегда заменяется отдельно проверенной моделью `unified-style-v6/rifle/rifle_unified_v6.glb`.

Проверки контролируют наличие точек `socket_grip_r`, `socket_grip_l` и `socket_reload`, движение обслуживаемой детали внутри клипа `reload`, синхронизацию длительности и достижимость обеих ладоней на всех шести телах персонажа.
