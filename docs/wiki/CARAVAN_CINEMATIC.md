# Отправка «Двенадцатого» и засада

Переход: `tutorialCaravanYard` → личная комната `randomRuinedRoad#intro_*`.
Идентификатор ролика: `caravan_departure_ambush`.

Постановка использует игровые модели и анимации: пять участников каравана,
четыре налётчика, два вьючных брамина. После открытия ворот колонна выходит
со двора. На тракте разыгрывается 25-секундная последовательность:

| Время | Событие |
| --- | --- |
| 0–4,4 с | Движение колонны по южному подходу к мосту |
| 4,4–8 с | Выход налётчиков с двух обочин, первый взрыв и огонь |
| 8–18 с | Ответный огонь, отход браминов, ещё два взрыва, потери |
| 18–22 с | Уход выживших из кадра |
| 22–25 с | Общий план последствий: три погибших союзника и три налётчика |

Постановка привязана к открытой дороге южнее крупных опор и модулей
авторской локации. Высота асфальта учтена при размещении персонажей.

`RoaCaravanDepartureCinematic` управляет монтажом, затемнением, подписями,
пропуском и восстановлением управления. `RoaCaravanAmbushStage` отвечает за
состав, траектории, выстрелы, взрывы и итоговые позы. Загрузка актёров завершается
до открытия кадра; скрытая предварительная загрузка также проверяется пробой.

Погибшие в постановке — декоративные актёры, не контейнеры с добычей. Они не
заменяют обязательных квестовых NPC и не меняют серверные жизни, награды или
задания. Итог восстанавливается после пропуска и повторного подключения к
личной комнате, а при выходе из неё декорации удаляются.

Сервер временно приостанавливает ИИ и боевые действия в этой личной комнате.
Действие `kromkaOnboardingAction/finish_cinematic` снимает паузу только для
владельца и правильного ролика. Оно идемпотентно и не продвигает задание.
Предельная пауза — 125 секунд, включая загрузку; отключившийся клиент не может
оставить комнату замороженной навсегда. Обычные встречи на тракте не затрагиваются.

## Проверки

- `npm run check:kromka-onboarding`, `npm run check:unity-parity`.
- `unity-client/Tools/compile-check.ps1`.
- Меню Unity: **Realm of Ashes → Проверить постановку засады каравана**.
  Проба не сохраняет и не заменяет открытые сцены; кадры 1440×900 и 844×390
  помещаются в `Build/KromkaSceneCaptures/caravan-ambush`.
- Изолированный серверный прогон: `KROMKA_QA_SCOPE=onboarding`
  и `node tools/check-kromka-live-journey-local.js`. Проверяются реальные
  действия обучения, переход, завершение/повторный пропуск ролика и прибытие в Ключи.

Изменения C# появляются в браузерной игре после новой сборки **Кромка → Build WebGL**.
Обновление серверной защиты требует перезапуска локального Node-сервера.
Публикация на боевой сервер остаётся отдельной ручной операцией.
