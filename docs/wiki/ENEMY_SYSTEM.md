## v7.74.69 — heavy update pacing

Серверный ИИ мобов не менялся. Клиентское отображение мобов из v7.74.68 сохранено; добавлен кеш fog-of-war по тайлу, чтобы видимость мобов не пересчитывалась лишний раз при каждом коротком интервале.

## v7.75.82 — тематическая добыча врагов

Типы врагов получили явный `lootTier`: `raider`, `ghoul`, `superMutant`, `ashWolf`. Серверная добыча теперь собирается из тематических loot tables, поэтому разные враги дают разные ожидания после боя. Базовое серебро от `money` сохранено, а дополнительные предметы зависят от tier. Таблицы валидируются при старте сервера.

## v7.75.83 — редкие варианты врагов

При серверном спавне враг может получить редкий вариант: `scarred`, `swift` или `legendary`. Вариант меняет имя, здоровье, атаку, скорость, масштаб, XP, серебро и добавляет бонусную добычу. Большинство спавнов остаются обычными, поэтому варианты работают как заметные пики опасности.

Публичный snapshot врага передает `baseSpeed`, `scale`, `xp`, `atk`, `variantId` и `variantName`. Клиент строит модель с серверным масштабом, сохраняет эти поля при сетевой синхронизации/локальном восстановлении и добавляет тонкий цветной акцент у основания модели для редких вариантов.
