# Графика и настройки качества

Актуально для **v7.76.6**. Рендеринг выполняет Unity URP 17.5.0; страница
описывает пользовательские настройки качества и связанные визуальные системы
Unity-клиента.

Страницы про Three.js-тени legacy-клиента перенесены в
[`archive/`](archive/) и текущий рендеринг не описывают.

## Пресеты качества

Проект использует шесть штатных URP-пресетов `QualitySettings`:

| Пресет | Подпись в меню |
|---|---|
| Very Low | Очень низкое |
| Low | Низкое |
| Medium | Среднее |
| High | Высокое |
| Very High | Очень высокое |
| Ultra | Ультра |

Пресеты различаются тенями, LOD, лимитом текстурных mip-уровней и бюджетом
эффектов; переключение происходит стандартным `QualitySettings.SetQualityLevel`
без собственного параллельного графического конвейера.

- Меню настроек открывается через **Esc → Графика** (`RoaSystemCanvas`):
  выбор пресета, текущие тени/LOD/текстуры и переключение
  оконного/полноэкранного режима на PC.
- Выбор сохраняется локально в `PlayerPrefs`.
- Первый запуск на мобильном устройстве начинает со **Среднего** пресета;
  desktop использует штатный пресет проекта.
- Игровая LOS и дальность обзора от графического пресета не зависят: качество
  меняет только визуальное представление, а не серверные или геймплейные
  правила видимости.

## Освещение и время суток

`RoaWorldLighting` ведёт солнце, луну, сумерки и туман по серверному времени
мира и применяет авторские визуальные профили локаций (например, двор Старого
Клима). Ночь поддерживает читаемость отдельным лунным светом. Стратегическая
карта имеет собственный световой профиль: тёплый верхний свет, тёмное
основание и линейный туман за игровым центром, чтобы край диорамы растворялся
в фоне.

Контракт закреплён пробой **Realm of Ashes → Проверить день и ночь** и
проверками `npm run check:unity-lighting` и
`npm run check:unity-visual-cohesion`.

## Атмосфера глобальной карты

`RoaGlobalMapAtmosphere` создаётся при открытии стратегической карты и
полностью восстанавливает камеру и солнце при закрытии:

- **пост-обработка** через URP Volume: тонемаппинг ACES, мягкий Bloom,
  виньетка и цветокоррекция (флаг `renderPostProcessing` камеры включается
  только на время карты);
- **время суток** от авторитетного `worldHour` симуляции: высота, цвет и
  интенсивность солнца, тёплый рассвет/закат, холодная «лунная» ночь;
  визуальный час подтягивается к серверному плавно, через полночь — по кругу.
  Чистые формулы (`DaylightFactor`, `SunPitchDeg`, `SunIntensity`,
  `GradeFilter`) закреплены пробой представления карты;
- **тени облаков** — бесшовный процедурный cookie на солнце с медленным
  дрейфом (`m_SupportsLightCookies` в URP-ассете обязателен);
- **клубы дымки по краю диорамы** — процедурные billboard-квады
  (отключаются флагом `EdgeBillowsEnabled`); шейдер `Sprites/Default`
  включён в `RoaRuntimeShaderGuard`, чтобы стриппинг не выкинул его из
  player-сборки;
- **рельефное обрамление** — два ряда клонов авторских скальных кластеров
  (`RockCluster_*` из сцены `GlobalMapAuthored`) вдоль прямоугольного
  периметра диорамы (`RoaGlobalMap.BuildRimRidges`): настоящий MEP-арт, а не
  процедурная геометрия — правило «рантайм карты не создаёт собственный
  визуал» соблюдено. Сегменты напротив воды пропускаются (море продолжается
  в туман), клоны выгружаются вместе с авторской сценой. Рельеф внутри
  играбельной области — задача авторской сцены, процедурный шум сломал бы
  посадку маркеров.

## UI и разрешение

- `RoaUiScale` — единый `CanvasScaler` для всех канв: референс 1920×1080, на
  мобильных 1280×720 (UI в полтора раза крупнее).
- `Canvas.pixelPerfect` обязателен; тексты HUD и глобальной карты получают
  тень в один физический пиксель ради читаемой кириллицы.
- В WebGL device pixel ratio ограничен 1,5, а шрифт всех канв —
  `RoaUiFont.Default` (Noto Sans с кириллицей из `Resources/RealmUi/Fonts`),
  потому что системных шрифтов в WebGL нет.

## WebGL-поставка

- Сборка: меню **Realm of Ashes → Build WebGL** (`RoaWebGlBuild.cs`) →
  `public/unity/` (в .gitignore). Имена файлов — хэши содержимого, Brotli с
  decompression fallback, стрипинг движка ограничен `Assets/link.xml`.
- Модели: `npm run build:models-lite` создаёт облегчённые копии GLB в
  `public/assets/models-lite/` (оригиналы не трогаются — их хэши закреплены
  пайплайном утверждения). Сервер отдаёт lite-файлы с фолбэком на оригинал,
  Unity подставляет префикс через `RoaModelUrl.Lite`.
- Диагностика: `?roadebug=1` включает `RoaWebGlInputProbe` — FPS, позиция
  мыши, модуль EventSystem и фокус раз в 2 секунды в консоль браузера.

Шаги выкладки описаны в разделе «Деплой: Unity — основной клиент»
[`docs/UNITY_PORT.md`](../UNITY_PORT.md).

## Рельеф глобальной карты

Меню **Realm of Ashes → Авторинг → Сгенерировать рельеф глобальной карты**
(`RoaGlobalMapReliefAuthoring`) детерминированно строит поле высот из
авторских данных `data/global-map.json`: холмы по биомам клеток
(`rocky_hills` — хребты, `green_lowland` — пологие волны, `scrap_field` —
бугры, `dry_lake` — котловины), впадина воды, выровненные коридоры дорог и
площадки узлов/ориентиров. Инструмент:

1. заменяет меши девяти `GroundTile_X_Y` на сетки с высотами — ассеты
   `GM_Mesh_Relief_X_Y` в `Art/GlobalMap/Meshes` (GUID стабилен,
   переиспользуются);
2. пересаживает декорации сцены по дельте «старый рельеф → новый»
   (повторный запуск идемпотентен);
3. пишет поле в `Resources/RealmOfAshes/GlobalMapRelief.asset` — рантайм
   (`RoaGlobalMapRelief.HeightAt` в `PointToWorld` карты) сажает маркеры,
   отряды, территорию и подписи на рельеф. Нет ассета — карта плоская.

Сцену инструмент **не сохраняет** — художник просматривает результат и
сохраняет сам. **После генерации сцену обязательно сохранить**, иначе
рантайм-ассет высот разойдётся с плоской землёй. Меню «Разгладить рельеф»
возвращает плоскость той же процедурой с нулевым полем.

Поверх рельефа работает **генератор окружения** («Авторинг → Сгенерировать
окружение: горы и реки», `RoaGlobalMapMountainsRiversAuthoring`): реки
трассируются стоком от высоких гребней к западному океану, русла врезаются в
поле высот (тайлы пересобираются), ленты воды — меши-ассеты
`GM_Mesh_River_N` с авторским материалом океана. Горы собираются из
**«штампов» демо-сцен MEP** (`MEP_Scenes/Scene_03`, `Scene_04`): кластеры
Cliff-префабов, расставленные художником пака, извлекаются с относительными
трансформами и посадкой относительно террейна (демо-сцены открываются
аддитивно только на чтение и закрываются без сохранения), затем композиции
ставятся на гребни нашего поля высот с ориентацией вдоль хребта; промежутки
добивает сетка одиночных пиков. Клоны получают запечённые материалы из
`Art/GlobalMap/MEPMaterials` (недостающие копии создаются автоматически по
той же конвенции URP Lit + исходные текстуры). Контейнеры
`GeneratedMountains_AUTHORED`/`GeneratedRivers_AUTHORED` пересоздаются при
каждом запуске; этот инструмент сцену **сохраняет** сам. Дороги генерирует
существующий `RoaGlobalMapRoadAuthoring` из `data/global-map.json`.

**Ориентиры** («Авторинг → Сгенерировать ориентиры из MEP-сцен»,
`RoaGlobalMapLandmarkAuthoring`) пересобирают слой `Decor`: композиции из
демо-сцен пака раскладываются по биомам `data/global-map.json` — лагеря у
дорог, сухостой в низинах, каменные россыпи на свалках; 19 ориентиров с
именами `Curated_*` (пин контракта — не меньше 15). Запускается после
генератора рельефа (читает запечённое поле высот).

**Текущее состояние карты — только рельеф**: сгенерированное окружение
(биомные зоны из демо-сцен, горы-штампы, реки, MEP-ориентиры) удалено
меню «Авторинг → Очистить сгенерированное окружение»; слой `Decor` пуст.
Генераторы (`RoaGlobalMapBiomeSceneAuthoring`,
`RoaGlobalMapMountainsRiversAuthoring`, `RoaGlobalMapLandmarkAuthoring`)
остались в проекте как эксперименты — окружение можно пересоздать, но
пины контрактов рассчитаны на чистую карту.

Полный порядок пересборки базовой карты: «Разгладить рельеф» → биомы 3.1 →
дороги 3.2 → детали и океан 3.4 → «Сгенерировать рельеф». Поле высот
ложится поверх авторской плоскости земли (−0.13, `ExpectedVisibleGroundY`) —
нулевой рельеф возвращает ровно исходную поверхность.

## Модели и коллайдеры

GLB-модели общие для Unity и legacy-клиента и загружаются glTFast без
конвертации. После изменения или пересборки GLB нужно обновить серверный
collider-каталог:

```bash
npm run build:colliders
```

Не редактируйте сгенерированные GLB и
`public/assets/models/wasteland/model-colliders.json` вручную — генераторы
находятся в `tools/`.

## Проверка

```bash
npm run check:assets
npm run check:unity-lighting
npm run check:unity-visual-cohesion
npm run check:unity-ground-dressing
npm run check
```

После визуальных изменений дополнительно проверяются desktop и mobile
landscape в собранном клиенте: переключение всех пресетов, день/ночь и
отсутствие раскрытия объектов через fog-of-war.
