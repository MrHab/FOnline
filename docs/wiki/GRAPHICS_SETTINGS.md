# Графика и настройки качества

Актуально для **v7.76.6**. Основная сцена использует WebGL/Three.js, sRGB и
ACES Filmic tone mapping. Один и тот же набор пресетов управляет разрешением,
тенями, fog-of-war, эффектами, детализацией рельефа и текстурным бюджетом.

## Пресеты

| Пресет | Pixel ratio desktop / mobile | Солнечные тени | Shadow map | Terrain details |
|---|---:|---|---:|---:|
| Low | 0.80 / 1.00 | нет | не рендерится | 0.28 |
| Medium | 1.15 / 1.20 | нет | не рендерится | 0.58 |
| High | 1.50 / 1.50 | только desktop | 2048 | 0.88 |
| Ultra | 2.00 / 2.00 | только desktop | 4096 | 1.00 |

По умолчанию desktop выбирает High, mobile — Medium. Pixel ratio ограничен
значением 2.0 и дополнительно умножается на адаптивный render scale. При
устойчивом падении FPS scale постепенно уменьшается до собственного floor
пресета, а после восстановления производительности возвращается к 1.0.
На desktop Ultra исходный backbuffer дополнительно ограничен бюджетом 4 млн
пикселей. В обычной сцене адаптация сохраняет не меньше нативного разрешения;
только при не менее чем шести актёрах и FPS ниже 42 в течение двух секунд
разрешён аварийный floor 0.92x. Возврат требует пяти секунд без толпы или при
FPS не ниже 58. DOM-интерфейс при этом всегда остаётся в полном разрешении.

Аппаратный MSAA включается только если расчётный backbuffer меньше 2,5 млн
пикселей. На больших и supersampled canvas он отключается при создании WebGL
context: нативная плотность уже сглаживает края, а дорогой multisample resolve
не повторяется каждый кадр.

## Настоящие и дешёвые тени

Desktop High/Ultra включает реальный directional-light shadow pass:

- High использует карту 2048 и базовую целевую частоту обновления 15 Гц;
- Ultra использует карту 4096 и базовую целевую частоту 24 Гц;
- фактическая частота адаптируется к FPS;
- при не менее чем шести актёрах и FPS ниже 48 Ultra использует устойчивый
  load-tier 3072; при трёх актёрах он снимается сразу, а при четырёх-пяти —
  после трёх секунд с FPS не ниже 58;
- caster-ы ограничиваются типом объекта и радиусом пресета;
- крыша торговца, fog-маски, glow, снаряды, подписи и мелкие декоративные
  объекты исключаются из shadow pass;
- ночью солнечный источник и его тени отключаются, а читаемость поддерживает
  отдельный moon light без теней.

Фокус shadow-camera стабилен в точке мира `{ x: 0, z: 0 }`. Она не следует за
игроком: это предотвращает дрожание проекции и лишние пересчёты карты при
обычном движении.

Low, Medium и все мобильные пресеты не запускают солнечный shadow pass.
`renderer.shadowMap` при этом технически остаётся включённым, чтобы не
перекомпилировать материалы на проблемных мобильных GPU; `sun.castShadow` и
обновления карты выключены. Игроки, враги и некоторые предметы используют
дешёвые псевдо-contact shadows.

Подробнее: [динамические тени](DYNAMIC_SHADOWS.md) и
[инициализация shadow budget](SHADOWS_INIT_AND_BUDGET.md).

## Текстурный бюджет рельефа

| Платформа и пресет | Max color | Max data | Layer normals | Displacement |
|---|---:|---:|---|---|
| desktop Low | 768 | 512 | нет | нет |
| desktop Medium | 1280 | 1024 | нет | нет |
| desktop High | 2048 | 1024 | да | да |
| desktop Ultra | 4096 | 2048 | да | да |
| mobile Low/Medium | 1024 | 768 | нет | нет |
| mobile High | 1280 | 1024 | нет | нет |
| mobile Ultra | 1536 | 1024 | нет | нет |

Ground material использует
`public/assets/textures/wasteland/wasteland_ground_albedo_v777.webp`; normal,
roughness, AO и height выбираются согласно бюджету устройства. Albedo не
содержит запечённого освещения и корректно реагирует на смену времени суток.

Low на desktop не загружает полный PBR-набор. Displacement разрешён только на
desktop High/Ultra, где рельефная геометрия получает достаточно сегментов.
Мобильные пресеты сохраняют PBR-материалы, но отключают layer normals и
displacement.

## Настройки, применяемые вместе

Смена пресета обновляет:

- effective pixel ratio и адаптивный scale;
- shadow type, map size, caster budget и update pacing;
- частоту обновления визуальной fog-сетки;
- лимит эффектов, beam-ов, muzzle lights и плавающих подписей;
- плотность декалей и деталей рельефа;
- размер процедурных текстур и лимит загружаемых PBR-карт.

Игровая LOS и дальность обзора от графического пресета не зависят. Качество
может менять только визуальное представление fog-of-war, а не серверные или
геймплейные правила видимости.

## Модели и коллайдеры

Совместимые primitive-части одного skinned GLB используют общий `Skeleton`,
если полностью совпадают bone references, inverse/bind matrices и bind mode.
Это не меняет деформацию и материалы, но устраняет повторные skeleton updates.
При толпе idle-анимации тяжёлых NPC и торговца распределяются по стабильным
фазам и ограничиваются 20 Гц; атака, урон, диалог, hover/selection, движение и
поворот не замедляются.

После изменения или пересборки GLB нужно обновить серверный collider-каталог:

```bash
npm run build:colliders
```

Не редактируйте сгенерированные GLB и
`public/assets/models/wasteland/model-colliders.json` вручную. Генераторы
находятся в `tools/`.

## Проверка

```bash
npm run check:assets
npm run check:client
npm run check
```

После визуальных изменений дополнительно проверяются desktop и mobile
landscape: переключение всех пресетов, день/ночь, движение рядом с крупными
caster-ами и отсутствие раскрытия объектов через fog.
