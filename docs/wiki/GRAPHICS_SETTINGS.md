# Графика и настройки качества

Рендеринг выполняет Unity URP 17.5.0; страница описывает пользовательские
настройки качества и связанные визуальные системы Unity-клиента.

## Пресеты качества

Проект использует шесть штатных URP-пресетов `QualitySettings`:

| Пресет | Подпись в меню |
|---|---|
| Very Low | Очень низкое |
| Low | Низкое |
| Medium | Среднее |
| High | Высокое |
| Very High | Очень высокое |
| Ultra | Ультра |

Пресеты различаются тенями, LOD, лимитом текстурных mip-уровней и бюджетом
эффектов; переключение происходит стандартным `QualitySettings.SetQualityLevel`
без собственного параллельного графического конвейера.

- Меню настроек открывается через **Esc → Настройки графики**
  (`RoaSystemCanvas`): выбор пресета, текущие масштаб рендера, тени, туман
  войны, LOD, сглаживание и текстуры, а на PC — переключение
  оконного/полноэкранного режима.
- Выбор сохраняется локально в `PlayerPrefs` (`roa.graphicsQuality`).
- Первый запуск на мобильном устройстве начинает со **Среднего** пресета;
  desktop использует штатный пресет проекта.
- Игровая LOS и дальность обзора от графического пресета не зависят: качество
  меняет только визуальное представление, а не серверные или геймплейные
  правила видимости.

## Освещение и время суток

`RoaWorldLighting` ведёт солнце, луну, сумерки, туман и пост-обработку
локальной сцены. По умолчанию час зафиксирован на 16:12; с включённым
`FollowServerWorldHour` компонент раз в 10 секунд читает `sim.worldHour` из
`/api/wasteland`. Базовый визуальный профиль выбирается по типу локации
(`settlement_warm`, `resource_dust`, `hostile_cold`, `wasteland_neutral`),
поверх него накладывается авторский `visualProfile` локации. Ночь
поддерживает читаемость отдельным лунным светом. Стратегическая карта имеет
собственный световой профиль: тёплый верхний свет, тёмное основание и линейный
туман за игровым центром, чтобы край диорамы растворялся в фоне.

Контракт закреплён пробой **Realm of Ashes → Проверить день и ночь**.

## UI и разрешение

- `RoaUiScale` — единый `CanvasScaler` для всех канв: референс 1440×810, на
  мобильных 1280×720, `matchWidthOrHeight = 0.5`.
- `Canvas.pixelPerfect` обязателен; тексты HUD и карты мира получают
  тень со смещением в один пиксель ради читаемой кириллицы.
- Шрифт всех канв — `RoaUiFont.Default` (Noto Sans с кириллицей из
  `Resources/RealmUi/Fonts`), потому что системных шрифтов в WebGL нет. На
  телефонах и планшетах WebGL-шаблон ограничивает device pixel ratio 1,5.

## WebGL-поставка

- Сборка: меню **Кромка → Build WebGL** (`RoaWebGlBuild.cs`) →
  `public/unity/` (в .gitignore). Имена файлов — хэши содержимого, Brotli с
  decompression fallback, стрипинг движка ограничен `Assets/link.xml`.
- Текстуры художественных паков (`Assets/MEP`) получают предел 1024 для
  WebGL постпроцессором импорта `RoaWebGlTextureBudget`; уже импортированное
  приводит к бюджету **Кромка → Авторинг → Бюджет текстур WebGL**, проверяет
  **Кромка → Проверки → Бюджет текстур WebGL**.
- Модели: тела персонажа и библиотека анимаций лежат в сборке префабами
  (`RoaModelPrefabCatalog`), остальные GLB загружаются по URL через glTFast.
  `npm run build:models-lite` создаёт облегчённые копии GLB в
  `public/assets/models-lite/` (оригиналы не трогаются — их хэши закреплены
  пайплайном утверждения). Сервер отдаёт lite-файлы с фолбэком на оригинал,
  Unity подставляет префикс через `RoaModelUrl.Lite`.
- Диагностика: `?roadebug=1` включает `RoaWebGlInputProbe` — FPS, позиция
  мыши, модуль EventSystem и фокус раз в 2 секунды в консоль браузера.

Шаги выкладки описаны в разделе «Деплой: Unity — единственный клиент»
[`docs/UNITY_PORT.md`](../UNITY_PORT.md).

## Модели и коллайдеры

После изменения GLB персонажей и существ в `public/assets/models/wasteland/`
нужно обновить actor collider-каталог:

```bash
npm run build:colliders
```

Коллизий окружения в этом каталоге нет. Не редактируйте GLB и
`public/assets/models/wasteland/model-colliders.json` вручную — генераторы
находятся в `tools/`.

## Проверка

```bash
npm run check:assets
npm run check
```

После визуальных изменений дополнительно проверяются desktop и mobile
landscape в собранном клиенте: переключение всех пресетов, день/ночь и
отсутствие раскрытия объектов через fog-of-war.
