# Предметы на земле

## Серверное состояние

Предметы на земле хранятся в серверной комнате в коллекции `groundItems`. Публичное состояние предмета содержит идентификатор записи, тип предмета, количество, координаты, автора выбрасывания и время создания.

Все игроки одной комнаты получают общий снимок. Клиент создаёт по нему компактную цветовую 3D-модель свёртка; постоянных подписей над предметами нет.

## Выбрасывание

Клиент отправляет `dropItem`, а сервер проверяет, что:

- игрок жив;
- предмет допустим и не является встроенными кулаками;
- указанное количество действительно есть в инвентаре;
- точный runtime-экземпляр оружия не содержит патронов в магазине;
- у игрока есть 1 ОД;
- предложенная позиция находится не дальше трёх метров и пригодна для перемещения.

При необходимости сервер выбирает безопасную позицию рядом с игроком. После успеха он списывает 1 ОД, удаляет предметы из инвентаря, создаёт запись на земле и рассылает `groundItemDropped` вместе с актуальным состоянием.

Для отзывчивости клиент может предварительно списать ОД действия с инвентарём, но при отказе восстанавливает их. Окончательным остаётся серверный ответ.

## Поднятие

Для `pickupGroundItem` сервер проверяет существование записи, дистанцию до неё и грузоподъёмность. Поднять можно только всю лежащую стопку: если она целиком не помещается, операция отклоняется.

После успеха предмет удаляется из `groundItems`, добавляется в инвентарь, а комнате рассылаются `groundItemPicked` и обновлённый снимок. Полное состояние также приходит через `groundItemsSnapshot`.

При смерти в PvP сервер может выгрузить инвентарь погибшего в эту же систему
предметов на земле. Поскольку ground-item хранит базовый id, патроны из магазинов
оружия в рюкзаке выпадают отдельными стопками боеприпасов. Не подобранные записи
удаляются серверной очисткой через 30 минут.

## Взаимодействие и видимость

Универсальное взаимодействие выбирает ближайший видимый свёрток примерно в радиусе 2,7 метра. Туман войны управляет отображением и выбором цели на клиенте. Сервер не доверяет этому представлению и при поднятии отдельно проверяет существование предмета, расстояние и вес.
