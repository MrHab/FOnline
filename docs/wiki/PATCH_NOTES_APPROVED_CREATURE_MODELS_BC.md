# Утверждённые модели существ B+C

В игру интегрированы шесть ранее утверждённых модей: брамин, геккон пустоши, огненный геккон,
пепельный волк, радскорпион и мутировавший муравей.

## Визуальный стиль

- Геометрия B сохраняет читаемый низкополигональный силуэт и органичную анатомию.
- Материалы C используют приглушённую палитру, пыль, потёртости и локальные следы износа.
- Все PBR-карты размером `512 × 512 px` встроены в GLB; внешние текстурные файлы не требуются.

## Риги и анимации

Каждая модель содержит полный деформирующий риг и шесть игровых действ:

- `idle` — спокойная стойка;
- `walk` — ходьба;
- `run` — бег;
- `attack` — видовая атака;
- `hurt` — реакция на урон;
- `death` — завершённая смерть с удержанием последнего кадра.

Ходьба и бег выбираются по фактической скорости существа. Атака, урон и смерть переключают клипы
по игровому состоянию. Для каждого экземпля клонируется отдельный скелет, поэтому стаи не синхронизируют
кости между разными существами.

## Загрузка и коллизии

- Модели загружаются по требованию, когда существо впервые появляется в локации.
- Общая версия URL принудительно обновляет кэш браузера.
- Коллайдеры пересобраны из фактической геометрии. Боевая анимация не раздувает проходимый габарит.

## Приёмка и воспроизводимость

В runtime можно попасть только из одобренного review-GLB. Сборщик сверяет документ `APPROVE`, review-отчёт,
точные байты кандидата и воспроизводимый runtime-хеш. Автопроверка дополнительно загружает все модели через
Three.js, клонирует их скелеты и проигрывает все шесть клипов.

```bash
npm run build:approved-creatures
npm run check:approved-creatures
```

Этот патч не заменяет гуманоидных НПС, обувь или окружение: их прежние приёмки не разрешали автоматическую
интеграцию в игру.
