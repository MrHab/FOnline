# v7.74.7 — Flat Roof Fog Fix

## Что исправлено
- Убраны серые вертикальные столбы под ячейками крыши.
- Внутренний fog-of-war больше не строится как высокий 3D-box от пола до крыши.
- Туман войны внутри здания теперь рисуется только плоской напольной маской на тех ячейках помещения, которые игрок не видит.
- Крыша остается настоящим визуальным перекрытием сверху, а fog-of-war только затемняет невидимую часть пола/помещения.

## Почему
Вертикальные fog-volume боксы были техническим приемом для скрытия невидимого интерьера, но визуально выглядели как серые колонны. Это неправильно: игрок не должен видеть технические столбы.
