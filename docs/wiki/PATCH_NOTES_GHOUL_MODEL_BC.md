# Цельный B+C-гуль

Процедурная составная заготовка гуля заменена полноценной моделью в едином
стиле с современным персонажем.

## Что изменилось

- Тело собрано как одна связная гуманоидная поверхность на основе
  утверждённой Quaternius-топологии персонажа v5.
- Мутация заложена в геометрию: голова постоянно вынесена вперёд, шея и
  спина образуют хищный излом, грудная клетка сжата, плечи асимметричны,
  конечности истончены, щёки запали, нос разрушен, а челюсть выдвинута.
- Семь B+C-материалов используют высохшую оливковую кожу, локальную
  пепельную и некротическую ткань, рубцы, угольное нижнее бельё, ломкие ногти
  и мутные янтарные глаза.
- Волосы, брови, одежда и экипировка не вшиты в тело. Гуль появляется
  босиком и только в нижнем белье, как было утверждено для базовых существ.

## Риг и анимации

Полный деформирующий риг содержит 65 суставов, включая пальцы. В GLB встроены:

- `idle`;
- `walk`;
- `run`;
- `attack`;
- `hurt`;
- `death`.

Атака заменена двухручным хищным выпадом. Обе кисти участвуют в движении,
пальцы раскрыты и не пересекаются. Клиент переключает действия по состоянию
гуля, выбирает `walk` или `run` по фактической скорости и сохраняет финальный
кадр смерти.

## Загрузка и физика

- Тяжёлый `5,95 МБ` GLB не входит в начальную загрузку мира и запрашивается
  только при появлении гуля.
- Версия URL обновлена, поэтому браузер не использует старую модель из кэша.
- Skinned mesh клонируется с отдельной копией скелета для каждого гуля;
  несколько экземпляров не управляют костями друг друга.
- Полный визуальный габарит учитывает двухручный выпад, а ходовой коллайдер
  ограничен корпусом, поэтому раскрытые руки не перекрывают проход.

## Приёмка и воспроизводимость

Художественный критик подтвердил отличимый силуэт в `112 × 112 px`, все
шесть действий, контакт стоп с землёй, устойчивое восстановление и завершённую
смерть. Утверждён только review GLB с SHA-256:

`DCAA6F7E2A2C48D3C89F9089399BE2BC4B12383265C2B16B5C825A2AB105CAF1`.

Runtime-сборщик сверяет документ `APPROVE`, review-отчёт и точные байты,
повторно выпускает модель в Blender и пересобирает коллайдеры. Проверка
контролирует связность тела, PBR-карты, 65-суставный skin, шесть клипов,
метаданные приёмки, размеры и интеграцию загрузчика.

```bash
npm run build:ghoul-model
npm run check:ghoul-model
```
