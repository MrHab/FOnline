# v7.74.8 — Inside Corner Vision Fix

## Что исправлено
- Исправлена ситуация, когда у игрока в углу здания почти полностью пропадал обзор помещения.
- Если игрок уже находится внутри здания торговца, обзор помещения теперь считается локально внутри комнаты, а не через внешние стены здания.
- Внешние стены по-прежнему блокируют обзор снаружи.
- Крыша по-прежнему скрывается по ячейкам сетки, но теперь не «закрывает» комнату только из-за того, что игрок стоит в углу рядом со стеной.
- Видимость торговца, предметов и внутренних ячеек крыши синхронизирована с новой локальной проверкой для игрока внутри помещения.

## Причина
Глобальный LOS/fog-of-war мог начинать луч обзора из технической клетки, которая пересекалась с угловым wall-blocker. Из-за этого система считала, что игрок не видит даже помещение, в котором сам находится.
