# v7.65.0 — Location Loading Screen

Патч добавляет полноценный экран загрузки при переходах между локациями.

## Что изменено

- Добавлен полноэкранный экран загрузки в стиле ржавой постапокалиптической консоли.
- При переходе через выход локации игра сначала показывает экран загрузки, даёт браузеру его отрисовать, и только потом начинает тяжёлую пересборку мира.
- Игровой ввод блокируется на время перехода:
  - движение останавливается;
  - автоогонь отключается;
  - мобильное прицеливание и стик сбрасываются;
  - клики по HUD не проходят сквозь экран загрузки.
- Перед сборкой новой локации заранее подгружаются основные текстуры:
  - terrain base/normal/roughness/AO/height по текущему пресету качества;
  - ground-декали торговой локации;
  - дерево, металл, каменные материалы;
  - тени, glow и служебные текстуры диорамы.
- Включён `THREE.Cache`, чтобы предзагруженные картинки повторно использовались TextureLoader и меньше дёргали браузер во время перехода.
- После сборки локации выполняется предварительная компиляция материалов/шейдеров через `renderer.compile(scene, camera)`.
- Перед скрытием загрузки выполняется первый рендер новой сцены, чтобы игрок не видел пустой кадр, пропавшие объекты или мигающие тени.
- Статические тени обновляются после загрузки, а не в середине перехода.

## Что не изменялось

- Боевая логика.
- Урон, AP, патроны.
- Сетевая синхронизация.
- Сохранения.
- Объёмные terrain-текстуры и PBR-материалы.
