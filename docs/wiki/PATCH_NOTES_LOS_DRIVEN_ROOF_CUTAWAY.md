# v7.74.5 — LOS Driven Roof Cutaway

## Основное изменение
Крыша здания торговца больше не управляется расстоянием до здания. Теперь она управляется тем же полем обзора игрока, которое используется для NPC, предметов, трупов и других игроков.

## Как работает новая логика
- Интерьер здания разделен на локальные зоны обзора.
- Крыша разделена на отдельные сегменты.
- У каждого сегмента крыши есть точки проверки под ним.
- Если хотя бы одна точка под сегментом реально видима игроку по `line of sight`, этот сегмент крыши скрывается.
- Если точки под сегментом не видны из-за стены, дерева или другого `blocksVision`, сегмент крыши остается видимым.

## Что исправлено
- Убрано скрытие всей крыши при приближении к зданию.
- Крыша больше не исчезает просто потому, что игрок стоит рядом с фасадом.
- Боковые и задние стены продолжают блокировать обзор.
- Если игрок видит только часть помещения через вход, раскрывается только соответствующая часть крыши.
- Невидимые зоны помещения остаются закрытыми туманом войны.
- Торговец и интерьерные объекты отображаются только если их позиции реально видны игроку.

## Технические изменения
- Добавлены функции проверки локальных точек здания через общий RTS/FOV fog:
  - `isTraderBuildingLocalPointVisible`
  - `isTraderWorldPointVisible`
  - `anyTraderLocalSamplesVisible`
- Добавлены сегменты крыши через `createTraderRoofSegment`.
- Добавлены сегменты внутреннего тумана войны через `createTraderFogSegment`.
- Обновление крыши перенесено после обновления тумана войны, чтобы использовать актуальные данные видимости.
