# v7.74.4 — Partial Roof Cutaway

## Что изменено
- Если игрок видит часть помещения под крышей со стороны фасада, скрывается только мешающая зона крыши.
- Передняя половина крыши и конек убираются при обзоре через вход/фасад.
- Задняя половина крыши остается на месте, пока игрок не войдет внутрь.
- При входе внутрь скрывается вся крыша, как и раньше.
- Боковые и задние стены по-прежнему не раскрывают интерьер сами по себе.
