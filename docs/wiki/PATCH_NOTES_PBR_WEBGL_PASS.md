# v7.61.0 — PBR WebGL Pass

Цель патча — закрепить найденный объём земли и перейти от плоских картинок к управляемому WebGL/PBR-пайплайну для первой локации.

## Что изменено

- Включён guarded PBR-lighting режим Three.js там, где версия движка это поддерживает.
- Все новые материалы проходят через единый PBR-контракт: металл не становится пластиком, земля остаётся шероховатой, камень/пыль не бликуют лишним.
- Для первой локации добавлены normal-карты для отдельных слоёв земли:
  - трещины;
  - гравий;
  - следы шин;
  - грязь/гарь;
  - сухая солома/дорога;
  - песочный микрорельеф.
- Прозрачные ground-слои теперь MeshStandardMaterial с normal map, а не плоский MeshBasicMaterial.
- Усилен relief-terrain: больше сегментов на ПК, выше displacement, сильнее normalScale и AO.
- Добавлены baked contact AO-декали под навесом, хранилищем, сараем, бочками, ящиками и заборами. Это даёт затемнение в местах контакта объектов с землёй без тяжёлого SSAO.
- Добавлены тёплые glow-декали и маленькие фонари у торговца и хранилища. На ПК/высоких настройках они дают ограниченный PointLight, на мобильных остаётся дешёвый emissive/glow.
- Добавлена instanced-сухая трава по краям первой локации: больше деталей почти без роста draw calls.
- Увеличена anisotropy до 16 для текстур, где видеокарта это поддерживает.
- Перенастроено освещение: меньше плоского ambient, больше бокового sun/rim-light, чтобы normal/displacement читались объёмно.
- CSS post-FX стал легче: цветокоррекция и мягкий псевдо-bloom без EffectComposer, чтобы не убить мобильный WebGL.

## Что не сделано намеренно

- Deferred Shading не добавлен: для текущего Three/WebGL-проекта это тяжёлый переход и риск просадки FPS.
- KTX2/DXT/ETC2/ASTC пока не внедрены: для этого нужен отдельный загрузчик и подготовка ассетов. Сейчас используются WebP + mipmaps + anisotropy.
- Гексы визуально не включены: они не улучшают разрешение текстур и могут вернуть видимый технический рисунок.
