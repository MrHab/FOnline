# v7.62.0 — RAM Budget Streaming

Патч оптимизирует потребление оперативной памяти после появления PBR/relief-земли.

## Что изменено

- Добавлен texture budget по качеству графики:
  - Low/Mobile: маленькие карты, без displacement.
  - Medium: сниженные карты, normal map без тяжёлого displacement.
  - High: 2K base + 1K normal/roughness/AO/height вместо постоянной загрузки 4K/2K набора.
  - Ultra: полный 4K/2K набор для максимального качества на ПК.
- Добавлены облегчённые варианты terrain-текстур:
  - `relief_ground_base_2k_v762.webp`
  - `relief_ground_base_1k_v762.webp`
  - `relief_ground_normal_1k_v762.webp`
  - `relief_ground_roughness_1k_v762.webp`
  - `relief_ground_height_1k_v762.webp`
  - `relief_ground_ao_1k_v762.webp`
- Добавлен runtime-downscale как защита: если браузер всё-таки загружает текстуру крупнее текущего бюджета, она уменьшается перед загрузкой в WebGL.
- Убрана постоянная загрузка layer-normal карт на мобильных и средних/низких настройках.
- Displacement оставлен только там, где он оправдан:
  - ПК High/Ultra — включён.
  - Mobile/Low/Medium — выключен, объём держится normal map и светом.
- Снижена детализация геометрии terrain по пресетам, чтобы не держать лишние vertex buffers.
- Исправлена очистка worldGroup:
  - теперь при перестройке локации освобождаются одноразовые геометрии и клонированные материалы;
  - общие материалы/геометрии не удаляются;
  - это убирает накопление памяти при переходах и сетевом пересоздании локации.
- Удалены неиспользуемые старые тяжелые ground-текстуры из полной сборки.

## Почему не просто оставить всё в 4K

В WebGL JPEG/WebP после загрузки всё равно разворачиваются в несжатую RGBA-память. Один 4096×4096 texture map может занимать около 64 МБ в распакованном виде, а PBR-набор из base/normal/roughness/height/AO быстро съедает сотни мегабайт. Поэтому качество теперь выбирается по пресету, а не грузится целиком всегда.
