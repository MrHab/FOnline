# Service Scout compact v2

## Что изменилось

Разведботинки `scoutBoots` получили производственный набор из 18 GLB:
шесть вариантов посадки — два пола и три телосложения — с тремя LOD для
каждого варианта. Модели созданы в Blender специально для Realm of Ashes,
используют общий риг `humanoid_v1`, UV-развёртку и два PBR-материала.

Ботинки отображаются только при фактическом экипировании физического предмета.
Сервер формирует визуальную экипировку событий `shot` и `melee` из
авторитетного состояния игрока, поэтому изменённый клиент не может показать
не принадлежащий ему `scoutBoots`.

## Производственные характеристики

- 6 вариантов посадки: `female/male` × `slim/medium/large`;
- LOD0 / LOD1 / LOD2: 3900 / 1992 / 1100 треугольников;
- 65 суставов, не более четырёх весов на вершину;
- 2 PBR-материала на GLB;
- формат glTF 2.0 / GLB;
- оригинальная геометрия и текстуры, сторонних ассетов нет.

## Проверка

- Blender 4.5.12 LTS повторно импортировал все 18 GLB;
- проведена проверка desktop и mobile-landscape 844×390;
- специализированные проверки и полный `npm run check` прошли;
- независимый агент-критик утвердил точный evidence-digest.

## Текущие ограничения

Интеграция использует переходный адаптер, который разделяет GLB на левую и
правую статические части и крепит их к процедурным голеностопам. Текущая
система персонажа ещё не передаёт авторитетные `sex/bodyType`, поэтому в
браузере выбирается только `male_medium`; остальные 15 GLB опубликованы и
проверены, но пока не выбираются игроком.

Формальная BVH-проверка посадки и сенсорное тестирование на реальном мобильном
устройстве остаются следующими этапами. Это обновление не означает готовность
всей библиотеки 3D-ассетов.
