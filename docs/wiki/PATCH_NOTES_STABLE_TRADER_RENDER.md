# v7.66.0 — Stable Trader Render

Цель патча — убрать исчезновение окружения, частей модели игрока и мигание теней на первой торговой локации во время ходьбы.

Что изменено:

- торговая локация теперь считается ручной диорамой со стабильным рендером;
- для первой локации отключено runtime-скрытие статичных объектов по техническим клеткам;
- крупные ground-слои, тени, декали, торговец, хранилище, выход и set dressing больше не пропадают при пересчёте видимости;
- для объектов первой локации отключён стандартный `frustumCulled`, который мог отбрасывать крупные составные группы или плоские декали на один кадр;
- для модели игрока отключён frustum culling на всех мелких деталях персонажа, оружия и экипировки;
- shadow-caster больше не меняет позицию каждую секунду при статическом shadow cache, чтобы не было «плавания» и мигания теней;
- объёмный terrain, PBR-материалы и экран загрузки сохранены.

Компромисс:

- на первой локации рендерится вся ручная диорама целиком. Это немного больше нагружает GPU, но локация небольшая, поэтому стабильность картинки важнее агрессивного culling.
- на остальных локациях старый culling сохранён.

Проверка:

```bash
npm run check
```
