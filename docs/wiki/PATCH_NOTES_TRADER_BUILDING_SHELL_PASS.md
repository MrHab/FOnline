# v7.72.0 — Trader Building Shell Pass

## Что изменено

1. Убран потолок торгового здания. Теперь при срезе крыши интерьер открывается полностью.
2. С торговой локации удалены все объекты окружения, кроме самого здания торговца.
3. Здание увеличено до более убедительного масштаба:
   - ширина: 16.0 м
   - глубина: 11.2 м
   - высота стен: 4.6 м
4. Сохранены только базовые внутренние элементы для проверки масштаба: прилавок и две боковые полки.
5. Коллизии упрощены и оставлены только для стен здания, прилавка и полок.

## Координаты
- торговое здание: tx=15 tz=20
- центр здания в world-space: вычисляется через tileToWorld(15, 20)
- прилавок: смещение (+2.10, +1.95) от центра здания
- левая полка: смещение (-5.90, +1.20)
- правая полка: смещение (+5.90, +1.20)

## Зачем
Этот патч нужен как промежуточный этап: сначала проверяем читаемость масштаба, обзор через cutaway roof и корректность коллизий, а уже потом возвращаем городские объекты по одному.
