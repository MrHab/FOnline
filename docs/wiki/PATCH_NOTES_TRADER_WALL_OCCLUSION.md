# v7.74.0 — Trader Wall Occlusion

## Что изменено
1. Добавлена логика сокрытия интерьера торгового здания, если игрок находится снаружи и обзор перекрывает стена.
2. Теперь вместе с интерьером скрываются:
   - торговец (NPC)
   - ящики возле торговца
   - пол внутри здания
   - стойка и боковые стеллажи
3. Интерьер раскрывается только в двух случаях:
   - игрок вошел в пятно здания
   - игрок стоит у входа
4. Поведение крыши синхронизировано с этой логикой: крыша скрывается только когда интерьер должен быть виден.

## Логика зон
- здание торговца: центр tileToWorld(15, 20)
- зона интерьера: |dx| < 9.2 и |dz| < 6.6
- зона входа: |dx| < 5.4 и -9.4 < dz < -3.8

## Результат
Если стенка перекрывает обзор, игрок больше не видит, что находится внутри, включая торговца-NPC.
