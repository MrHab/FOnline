## v7.74.69 — heavy update pacing

- Оптимизированы частые тяжёлые обновления: fog-of-war, миникарты, динамические тени и DOM-readout.
- Миникарта использует кеш статичного слоя, а динамические маркеры рисуются отдельно.
- Проверка видимости сущностей кешируется по тайлу/версии тумана войны.
- Shadow-map обновляется только через адаптивный бюджет, а не сразу при каждом запросе.


## v7.74.67 — character session lock

- Каждая вкладка получает свой `clientInstanceId`.
- Socket `join` выдаёт `characterLeaseId`, а HTTP-синхронизация персонажа проверяет эту lease.
- Вторая вкладка с тем же персонажем не может перезаписать координаты активной вкладки.

## v7.74.51

- Стабилизировано длинное движение удалённых игроков: короткая экстраполяция теперь ограничена, старые `playerState` игнорируются по серверному времени, резкие коррекции заменены на плавное догоняние с лимитом скорости.

## v7.74.47

Следующий корректирующий патч плавности: без задерживающего буфера удалённых игроков. Серверный тик поднят до 20 Гц, клиент чаще отправляет позицию, а remote-модель получает лёгкое прогнозирование между snapshot-пакетами и быстрый snap только при телепорте/респавне.

## Правила развития

- Не возвращать видимую сетку мира.
- Не использовать псевдотени вместо настоящих теней.
- Не раскрывать интерьер через стены.
- Не добавлять changelog-файлы.
- После каждого изменения обновлять соответствующую страницу вики.


## v7.74.47

Patch 10, промежуточный безопасный шаг: сервер усилил проверки лута, контейнеров и предметов на земле. `lootEnemy`, `lootWorldContainer` и `pickupGroundItem` теперь получают снимок переносимого веса `carry`; сервер ограничивает выдачу предметов по весу и не удаляет лут, если предмет не помещается. `dropItem` дополнительно проверяет заявленное количество до выбрасывания. Полный перенос инвентаря на сервер остаётся следующим крупным этапом.

## v7.74.47

Готово: добавлена интерполяция удалённых игроков. Клиент хранит короткий буфер координат, отрисовывает remote-модели с небольшой задержкой и снапает их только при реальном телепорте/респавне.

## v7.74.43

Patch 9, промежуточный безопасный шаг: сервер проверяет боевые ресурсы атаки. Для `enemyHit` добавлены серверные проверки ОД, патронов в магазине и одноразового токена выстрела, чтобы дробовик/огнемёт/ракета не списывали расход за каждую задетую цель. Перезарядка подтверждается событием `reloadWeapon`. Полный перенос инвентаря на сервер остаётся отдельным следующим этапом.

## v7.74.42

- Исправлена проверка боевого попадания: сервер больше не отклоняет выстрел только из-за небольшого рассинхрона позиции игрока или из-за блокирующего тайла под самой целью.

## v7.74.41

Patch 8: `enemyHit` стал серверно-авторитетным. Клиент больше не передаёт готовый урон как источник истины; сервер проверяет комнату, цель, оружие, режим, дистанцию, линию атаки, шанс попадания и броню моба, после чего сам уменьшает HP цели. Клиент передаёт навыки, перки и стартовые черты персонажа для расчёта боевого профиля.

## v7.74.40

Ночь стала читаемой на мобильных: усилен лунный/ambient-свет, уменьшено CSS-затемнение, ночной туман стал тоньше. Тени от солнца ночью отключаются, а вместо них используется отдельный moonlight DirectionalLight без castShadow.

## v7.74.39

Пустая опасная комната больше не замораживает агро мобов в точке ухода игрока. Когда последний игрок покидает комнату, сервер сбрасывает chase/attack/investigate у мобов, запускает возврат домой и короткое фоновое AI-окно без сетевых snapshot и без дополнительного спавна. При возвращении игрока моб не должен продолжать погоню с того же места и той же фазы.

## v7.74.37

Patch 5: добавлена авторитетная очистка клиентских сетевых моделей по серверным snapshot. Сервер отправляет `roomId` в snapshot игроков и мобов, клиент игнорирует поздние пакеты из старой комнаты, отбрасывает устаревшие snapshot по времени `t` и очищает игроков, мобов, предметы на земле и контейнеры при входе, смене локации и респавне до применения нового `worldState`.

## v7.74.35

Исправлено мигание скрытых сетевых сущностей в тумане войны: удалённые игроки, мобы, трупы, предметы на земле и контейнеры сразу проверяются через RTS fog-of-war при каждом socket snapshot. Кнопка `Забрать всё` больше не применяет одиночный ответ по трупу как полный список мобов комнаты.

## v7.74.34

Patch 4: усилена очистка remote-player моделей после смерти, респавна, смены комнаты и реконнекта. Сервер отправляет расширенные события `playerLeft` и `playerRespawned`; клиент удаляет stale-модели по `socket.id` и `characterId`, а полный snapshot больше не возвращает мёртвых игроков.

## v7.74.33
