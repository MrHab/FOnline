# Крыша торговца и производительность

## Текущая модель

Крыша торговца — одна плоская непрерывная плоскость по размеру здания. У неё нет скатов, конька и визуального свеса. После создания геометрия не перемещается, не масштабируется и не разбивается на включаемые и выключаемые mesh-секции.

Отрисовка выполняется одним mesh и одним материалом. Клетки существуют только в лёгкой `DataTexture` alpha-mask и совпадают с мировой gameplay/fog-of-war сеткой `TILE = 2`.

## Как работает cutaway

Для каждой клетки маски код сначала проверяет fog-free область по набору world-space проб: центр, углы, края и промежуточные точки. Дополнительный screen-projection fallback открывает участок крыши, если его экранная проекция перекрывает видимую без тумана клетку земли. Поэтому решение не сводится к одной проверке центра через `isPointVisibleForGameplay()`.

- Mask `0`: участок закрыт и рисуется с opacity `1.0`.
- Mask `255`: участок открыт и рисуется с `openOpacity = 0.24`.
- `NearestFilter` сохраняет границы cutaway по клеткам без размытия между соседними значениями.

Меняется только содержимое маленькой alpha-mask. Геометрия, `visible`, scale, matrix и mesh count остаются стабильными.

## Почему геометрия не вырезается

Для крыши нельзя использовать удаление квадратов, `visible = false` для секций, нулевой scale или обновление матриц при каждом шаге. Такие варианты создавали разрывы, чёрные полосы и лишнюю работу на мобильных устройствах.

Текущий single-pass путь сохраняет цельную текстурированную поверхность и дешёво обновляет только прозрачность нужных world-tile участков.

## Видимость интерьера

Статическая геометрия интерьера может постоянно оставаться в сцене: непрозрачные участки крыши закрывают её визуально. NPC, игроки, враги, трупы, лут и интерактивные объекты продолжают подчиняться общей fog-of-war/LOS видимости.

## Тени крыши

Крыша исключена из настоящего shadow-map pass:

- `castShadow = false`;
- `receiveShadow = false`;
- `forceNoShadow = true`.

Это локальное правило крыши. Настоящие динамические солнечные тени в остальной сцене активны на desktop High/Ultra; на Low, Medium и mobile используются более дешёвые contact/baked эффекты.
