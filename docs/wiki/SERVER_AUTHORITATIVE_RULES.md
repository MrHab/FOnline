# Авторитетные правила сервера

## Сервер решает

Сервер должен быть источником истины для:
- положения игроков в MMO-комнате;
- врагов;
- смерти и респавна;
- лута врагов;
- предметов на земле;
- контейнеров мира;
- лечения других игроков;
- переходов между локациями;
- ресурсов мира: hp узлов, исчезновение руды/дерева и тайл карты после добычи.

## Клиент может решать

Клиент может локально решать:
- визуальные эффекты;
- анимации;
- UI;
- локальные подсказки;
- предварительный pathfinding;
- отображение fog-of-war по полученному миру.

## Нельзя доверять клиенту

Клиент не должен окончательно решать:
- сколько урона получил враг;
- сколько hp осталось у руды/дерева;
- должен ли ресурс исчезнуть с карты;
- есть ли предмет в контейнере;
- подобран ли предмет с земли;
- жив ли другой игрок;
- можно ли лечить цель вне дистанции;
- можно ли перейти в комнату без серверной проверки.

## Синхронизация

Все общие сущности должны иметь id и приходить в snapshots. Клиент должен уметь удалить локальную модель, если сервер больше не присылает такую сущность.


## v7.74.44 — лут и переносимый вес

- Сервер проверяет выдачу предметов из `lootEnemy`, `lootWorldContainer` и `pickupGroundItem` по снимку `carry` и собственной формуле максимальной грузоподъёмности.
- Труп или контейнер изменяются только на количество, которое сервер реально разрешил выдать.
- Если веса не хватает, сервер возвращает ошибку и не удаляет предмет из общего мира.
- Подбор предмета с земли разрешается только целым стаком; частичный подбор с земли пока не включён, чтобы не терять остаток.
- Это промежуточный шаг: полный серверный инвентарь остаётся отдельным этапом.

## v7.74.43 — боевые ресурсы

- Сервер хранит боевой ledger игрока: AP, магазин оружия, запас боеприпаса и spent-tokens короткого срока жизни.
- Перед нанесением урона сервер проверяет стоимость атаки и наличие патрона.
- Мультитаргет-атаки используют один `attackToken`, поэтому расход списывается один раз, а урон может применяться к нескольким целям.
- Перезарядка проходит через `reloadWeapon` и подтверждает AP/loaded/reserve на сервере.
- Пока инвентарь ещё не полностью серверный, клиент отправляет `combat`-снимок для начальной синхронизации магазина и боеприпасов; полный серверный инвентарь остаётся следующим этапом.

## v7.74.42

- Исправлена проверка боевого попадания: сервер больше не отклоняет выстрел только из-за небольшого рассинхрона позиции игрока или из-за блокирующего тайла под самой целью.

## v7.74.41 — урон по мобам

- Клиент больше не является источником истины по числу урона в `enemyHit`.
- Сервер проверяет цель, комнату, дистанцию, линию атаки, оружие, режим атаки и рассчитывает попадание/промах.
- Сервер рассчитывает сырой урон, броню моба, поглощение и итоговый HP.
- Клиентская визуализация остаётся только интерфейсной предикцией и сверяется с `ack`/`enemySnapshot`.
