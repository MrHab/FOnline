# Инициализация и бюджет динамических теней

## Безопасный запуск

Сцена, солнце и shadow budget создаются раньше модели игрока. Поэтому код теней не должен напрямую читать `player` во время первого прохода инициализации.

Фокус теней не зависит от готовности персонажа: `shadowFocusWorldPoint()` с момента запуска и во время игры возвращает фиксированную точку `{ x: 0, z: 0 }`. После создания игрока фокус не переключается на его координаты.

Безопасный helper `getAdaptiveShadowPlayerRef()` используется только для обнаружения движения динамического актёра и запроса внеочередного обновления активной shadow-map. Он не определяет позицию shadow-camera и не должен создавать TDZ-ошибку на login screen.

## Правила инициализации

- Login screen не должен зависеть от существования игрового персонажа.
- Shadow-camera сразу настраивается вокруг `{ x: 0, z: 0 }`.
- `renderer.shadowMap.enabled` сохраняет стабильный shader pipeline для всех пресетов.
- Реальный солнечный shadow pass разрешён только на desktop High/Ultra и только днём.
- На Low, Medium и mobile `sun.castShadow` остаётся выключенным.
- Запросы обновления можно накапливать до готовности renderer/sun; бюджет выполнит их только когда настоящий shadow pass активен.

## Адаптивный бюджет

При активных тенях `autoUpdate` выключен. Следующий shadow pass запрашивается по таймеру пресета или по событию: перестройка мира, смена качества, изменение солнечного света либо движение динамического актёра.

Фильтрация caster-объектов выполняется вокруг фиксированного центра локации. Радиус зависит от пресета: High — 42 world units, Ultra — 58. Объекты вне области и помеченные `forceNoShadow` не участвуют в проходе.

Если FPS проседает, бюджет снижает частоту фоновых обновлений. Он не переводит игру на другой пользовательский пресет.
