# Инициализация и бюджет динамических теней

Система теней должна быть безопасной на этапе загрузки клиента.

`02_renderer_world_map.js` создаёт сцену, свет и бюджет теней раньше, чем `04_player_model_visuals.js` создаёт объект `player`. Поэтому код теней не должен напрямую обращаться к `player` во время первого прохода инициализации. Для позиции фокуса теней используется безопасный доступ: до появления игрока фокус считается как `{ x: 0, z: 0 }`, после создания игрока — по реальным координатам персонажа.

Правила:

- login screen не должен падать из-за расчёта теней;
- shadow-camera может стартовать в нуле до создания персонажа;
- после создания персонажа тени фокусируются вокруг его позиции;
- динамические тени остаются включёнными, но пересчитываются через adaptive shadow budget;
- оптимизация теней не должна обращаться к игровым объектам, которые ещё не созданы.
