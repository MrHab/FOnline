# Торговец

## Назначение

Торговец позволяет покупать товары и продавать предметы из инвентаря.

## Визуальное размещение

Торговец находится внутри здания. Он отображается только если игрок реально видит интерьер через line-of-sight. Стены не должны позволять видеть NPC через себя.

## ПК

- покупка — клик по товару;
- продажа — перетаскивание предмета в торговую зону или двойной клик по предмету;
- при продаже стака открывается выбор количества.

## Мобильная версия

- окно торговца компактное и центрированное;
- левый стик остаётся активным;
- если игрок отходит слишком далеко, окно закрывается;
- продажа идёт через сетку предметов внутри окна торговца.

## Ограничения

- нельзя купить предмет, если не хватает денег;
- нельзя купить предмет, если он не помещается по весу;
- карточки недоступных товаров должны визуально затемняться.
