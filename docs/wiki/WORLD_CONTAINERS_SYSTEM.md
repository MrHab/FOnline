# Контейнеры мира

## Назначение

Контейнеры мира — общие ящики, сундуки и тайники. Их видят все игроки в комнате, а содержимое хранится на сервере.

## Серверное состояние

```js
room.containers = new Map()
```

Контейнер хранит id, название, позицию, tier и массив лута.

## Тематические tier v7.75.81

Контейнеры больше не используют одну плоскую таблицу добычи. Сервер выбирает loot table по `tier`:

- `survival` / `settlement` — вода, дерево, немного серебра и базовая медицина;
- `tools` — ресурсы, ремкомплект, кирка или топор, редкий шанс лёгкой обуви;
- `medical` — стимуляторы, аптечки, антибиотики и редкий набор доктора;
- `ammo` — разные типы патронов, серебро, редкий шанс оружия или ремкомплекта;
- `wasteland` — смешанный лут пустоши;
- `rare` — более ценные патроны, медицина, экипировка и редкий шанс оружия;
- `basic` — fallback для обычных контейнеров.

Таблицы проверяются при старте сервера: неизвестный `tier` в локации или неизвестный item id в таблице должен остановить запуск, а не превратиться в тихий пустой лут.

На клиенте контейнеры окрашиваются по `tier`. Пустые контейнеры становятся приглушёнными, чтобы игрок видел, что тайник уже обыскан.

## События

- `openWorldContainer` — открыть контейнер;
- `lootWorldContainer` — забрать предмет;
- `worldContainersSnapshot` — полный список контейнеров;
- `worldContainerUpdated` — содержимое изменилось.

## Правила

1. Клиент не создаёт контейнеры сам.
2. Лут не изменяется локально без сервера.
3. Если один игрок забрал предмет, окно обновляется у всех.
4. Если предмет не помещается по весу, нужно предложить частичный перенос.

## Видимость

Контейнер должен отображаться и быть доступен только если он реально виден или находится в допустимой зоне взаимодействия.
