# Динамические тени

## Текущее правило

Настоящий солнечный shadow-map pass используется только на desktop в пресетах **High** и **Ultra** и только днём. На **Low**, **Medium** и мобильных устройствах солнечный shadow pass отключён; объём сцены там поддерживают baked/contact AO и другие дешёвые приёмы.

`renderer.shadowMap.enabled` остаётся включённым для всех пресетов ради стабильного shader/material pipeline. Это состояние само по себе не означает, что солнце отбрасывает настоящие тени: активность прохода дополнительно ограничивается пресетом, типом устройства и освещённостью.

## Пресеты и бюджет

| Пресет | Солнечный shadow pass | Размер карты | Частота бюджета | Радиус caster-зоны |
|---|---|---:|---:|---:|
| Low | нет | 512 | 6/с, резервная настройка | 18 |
| Medium | нет | 1024 | 10/с, резервная настройка | 28 |
| High | desktop | 2048 | до 15/с | 42 |
| Ultra | desktop | 4096 | до 24/с | 58 |

Пресет по умолчанию — **High** на desktop и **Medium** на мобильных устройствах. Параметры карты, частоты и радиуса у Low/Medium сохраняются в конфигурации, но не запускают солнечный shadow pass.

## Обновление shadow-map

`renderer.shadowMap.autoUpdate = false`: дополнительный проход не выполняется на каждом кадре. При активных настоящих тенях код выставляет `renderer.shadowMap.needsUpdate` и `sun.shadow.needsUpdate` по бюджету:

- по таймеру пресета;
- после смены качества или перестройки локации;
- при заметном изменении солнца и времени суток;
- при движении динамического актёра.

При падении FPS адаптивный бюджет может временно уменьшить частоту фоновых обновлений, не меняя выбранный графический пресет.

Солнечные тени активны только при дневной освещённости (`sunlightAmount > 0.22`). Ночью shadow-map солнца выключен, а отдельный moonlight `DirectionalLight` работает без `castShadow`.

## Фиксированный фокус

`shadowFocusWorldPoint()` всегда возвращает центр локальной сцены:

```js
{ x: 0, z: 0 }
```

Shadow-camera и область отбора caster-объектов привязаны к этой фиксированной точке и **не следуют за игроком**. Это исключает дрожание и постоянную перестройку области теней при каждом перемещении персонажа.

Радиусы из таблицы измеряются вокруг `{ x: 0, z: 0 }`. В активный shadow pass попадают только разрешённые caster-объекты в пределах бюджета; объекты с `forceNoShadow`, включая крышу торговца, исключаются.

## Практическое следствие

Оптимизация High/Ultra основана на трёх ограничениях: фиксированная область, фильтрация caster-объектов и управляемая частота обновления. Low, Medium и mobile не расходуют бюджет на настоящий солнечный shadow pass.
