# Архив wiki

Страницы в этой папке описывают **legacy браузерный Three.js-клиент**
(`public/js/`, доступен только по `/legacy/`) и не являются источником текущих
контрактов. Актуальный клиент — Unity (`unity-client/`); текущие страницы
рендеринга: [камера и видимость](../CAMERA_AND_VISION.md) и
[графика и настройки качества](../GRAPHICS_SETTINGS.md).

- [DYNAMIC_SHADOWS.md](DYNAMIC_SHADOWS.md) — shadow-map тени Three.js.
- [SHADOWS_INIT_AND_BUDGET.md](SHADOWS_INIT_AND_BUDGET.md) — инициализация и
  бюджет теней Three.js.

Файлы `PATCH_NOTES_*.md` в корне wiki также считаются архивом конкретных
итераций.
