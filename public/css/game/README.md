# Разбиение `game.css`

Файл `public/css/game.css` теперь является загрузчиком через `@import`. Он подключает части из этой папки строго в исходном порядке.

Разбиение сделано механически, без изменения CSS-правил и без переписывания интерфейса. Если выполнить конкатенацию файлов `01_...` — `09_...`, получается исходный `game.css` до разбиения.

Порядок файлов менять нельзя:

1. `01_base_layout_hud.css` — Базовый layout, canvas, HUD, окна и основные панели.
2. `02_mobile_fullscreen_touch.css` — Мобильный fullscreen, touch/combat, landscape HUD и ранние мобильные фиксы.
3. `03_hud_minimap_inventory_progression.css` — HUD, миникарта, настройки, инвентарь, прогрессия и оверлеи v26–v30.
4. `04_mobile_inventory_trade_quality.css` — Мобильные правки, инвентарь, оружейная панель, журнал, торговля и качество UI v33–v48.
5. `05_loot_storage_trader_mobile.css` — Окна лута, контейнеры, хранилище, торговец и мобильная прокрутка.
6. `06_graphics_settings_time.css` — Кнопка fog-of-war, графические настройки, FPS, время суток и цветовой профиль.
7. `07_injuries_progression_perks_base.css` — Панели травм, окно развития, базовая сетка прогрессии и начальное дерево перков.
8. `08_perk_tree_layout_navigation.css` — Подгруппы дерева перков, активное перемещение, боковые ветки, зум и навигация.
9. `09_perk_tree_focus_and_overrides.css` — Фокус окна прогрессии, упрощение дерева, финальные правки подписей, линий и выравнивания.
