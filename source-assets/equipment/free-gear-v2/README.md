# Downloaded free gear masters

All selected sources use CC0. `sources.json` pins the source page, creator,
download URL and SHA-256. The Quaternius GLTF mirror is pinned to commit
`db3df04d1e4714298a09510b26fb6de6645138a2`; packed data URIs remain embedded.
The Bucket Helmet FBX and PNG are extracted by exact member names from the
pinned archive; no arbitrary archive path is used as a filesystem destination.

Verified primary source license pages:

- [Quaternius Ultimate Modular Men](https://quaternius.com/packs/ultimatemodularcharacters.html)
- [Quaternius Ultimate Modular Women](https://quaternius.com/packs/ultimatemodularwomen.html)
- [Quaternius Character Soldier](https://poly.pizza/m/PpLF4rt4ah)
- [Lucian Pavel Bucket Helmet](https://opengameart.org/content/bucket-helmet)

Regenerate downloads with `node tools/fetch-free-gear-sources.js`. These are
masters for isolated, refitted gear, not complete characters to spawn in-game.
Generated derivatives must record removed source body parts, material changes,
fitting and skinning. Availability here is not proof of runtime integration.
