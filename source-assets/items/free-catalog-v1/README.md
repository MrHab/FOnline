# Free item and equipment source candidates

Pinned CC0 masters selected on 2026-09-09. Run
`node tools/fetch-free-item-sources.js` to reproduce the download and extraction.
The generated `sources.json` records creator, source page, download URL, license,
archive member and SHA-256. Only selected models are retained here; ZIP caches
remain in the ignored `Build/SourceDownloads` directory.

These files are source candidates, **not proof of runtime integration**. The new
runtime catalog must separately record which source is used for each item, its
modifications, bounds and checksums. Weapon and older ground-library approvals
are not changed by this work.

CC0 notices for the Kenney packs are copied verbatim alongside the models.
Quaternius and Kenney individual model pages explicitly identify the assets as
Public Domain (CC0). The source pages and hashes are pinned by the downloader.
