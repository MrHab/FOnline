# Служебные ботинки «Полевой разведчик», compact v2

Статус: утверждённый художественный ассет, агент-критик — `APPROVED`.
Пользователь делегировал финальное решение критику фразой «Пусть критик
подтверждает». Runtime-интеграция разрешена; pull request разрешён только
после повторного QA уже интегрированного результата.

## Состав

- 6 вариантов посадки: 2 пола × 3 телосложения;
- 3 LOD на вариант: 3900 / 1992 / 1100 треугольников;
- единый скелет `humanoid_v1`, 65 joints, не более 4 весов на вершину;
- 2 PBR-материала, по 3 карты 256×256 на материал: Base Color, Normal,
  packed ORM;
- 10 предметных рендеров и 48 рендеров посадки;
- 8 проверочных поз на вариант: bind, idle, walk, run, crouch,
  one-handed ready, two-handed ready и heavy melee.

Строго проверяемый пакет находится в `production-preview/`. Он содержит ровно
83 файла: 18 GLB, 58 PNG, 6 fit-report JSON и 1 manifest JSON.

## Источник и лицензирование

Геометрия и текстуры созданы специально для Realm of Ashes. Сторонняя
геометрия и сторонние текстуры не импортировались. Художественный источник:
`service_boots_redesign_working.blend`. Manifest фиксирует SHA-256 исходника,
генераторов, GLB, рендеров и fit-отчётов.

## Воспроизведение и проверка

Сборка выполняется отдельными headless-процессами Blender через:

```powershell
node tools/art/build-service-boots-service-scout-review.js --reuse-valid
```

Строгая проверка:

```powershell
npm run check:service-boots-service-scout
```

Генератор получает художественную коллекцию из `.blend`, строит отдельный
skinned GLB для каждой пары пола и телосложения, создаёт LOD и PBR-карты.
Сгенерированные GLB не редактируются вручную.

## Ограничение review-этапа

Одобренные базовые body GLB не содержат полного runtime-набора боевых
анимаций. Поэтому fit-renderer использует детерминированные proxy-позы для
демонстрации деформации ботинок и скрытия областей `foot_l`/`foot_r`.
Это доказательство посадки, skinning и отсутствия видимых ступней, но не
замена будущей проверке на окончательных runtime-анимациях после одобрения
ассета.
