# Проверка паритета тумана войны

Дифференциальный тест: рядом лежат дословная транскрипция web-клиента
(`public/js/game/09_update_fog_movement_ai.js`) и алгоритм, перенесённый
в `Assets/Scripts/Game/RoaFogOfWar.cs`. Обе реализации гоняются по одним
и тем же случайным картам, ответы сравниваются потайлово.

Тест не зависит от Unity — обе стороны работают на голых массивах, поэтому
геометрию лучей можно проверить, не открывая редактор.

```bash
dotnet run -c Release --project unity-client/Tools/FogParityTest
```

Ожидаемый вывод: 460 800 запросов видимости, 120 000 точных OBB-лучей и
120 000 тайловых баллистических лучей, ноль расхождений.

## Что именно он ловит

Тест намеренно допускает наблюдателя, стоящего **на низком укрытии**: укрытие
проходимо (`authoredObjectBlocksMovement`, 02a:1898), и это не искусственный
случай. Ровно на нём и вскрылась ошибка переноса — `lineTilesBetween` (09:107)
не включает тайл наблюдателя, а первая версия порта включала, из-за чего игрок,
стоящий на ящике, прятал от себя всех присевших соседей. С той версией тест
даёт 284 расхождения.

Тест также падает, если ветка низкого укрытия не сработала ни разу: иначе он
«прошёл бы», ничего не проверив.
